## 1. 固定作品名称

**面向前沿科学问题的AI假设生成与研究计划设计平台**

该名称已经完成报名并不可修改。所有对外材料、页面标题、演示文案、接口说明和提交文件必须使用这一名称。

历史候选题名、神经机制方向题名和以产品代号作为申报名称的表述均已废止，不得继续作为作品名称或主定位；方向 B 仅作为代表性验证能力，不与方向 A 并列为默认申报主线。

## 2. 参赛定位

- 赛道：赛道一，科学问题。
- 方向：方向一，科学实验任务规划与反馈迭代中的 A“科学假设生成与研究计划设计”为作品主线。
- 验证能力：B 类实验规划、执行、数据分析和反馈迭代作为代表性假设的验证引擎，不替代 A 的正式交付要求。
- 产品边界：平台辅助研究者扩展检索、证据整理、假设搜索、研究计划设计和实验反馈能力；研究目标、风险边界、执行审批和核心科学结论由人类负责。

## 4. 对外科研流程

```text
前沿科学问题
  -> 可信资料与证据登记
  -> 问题理解和知识整合
  -> 候选假设生成
  -> 多维审查与人类审批
  -> 可执行研究计划
  -> 代表性实验或计算验证
  -> 结果分析与边界判断
  -> 假设和计划版本修订
```

假设评价不得依赖单一总分。至少分开记录：

- 证据充分性和来源可信度；
- 科学事实准确性；
- 创新性；
- 可证伪性；
- 研究计划可执行性；
- 资源、时间、伦理和安全风险；
- 反例、边界条件和不确定性。

## 5. 当前真实进展

### 当前 MVP 验收口径

- 当前产品口径固定为 **1 个黄金样例 + 3 个试运行题，共 4 题**。
- 黄金样例为 `SCI-096`；试运行题为 `SCI-031`、`SCI-097`、`SCI-118`。
- 正式账本当前机器验证为 `4/4`；`SCI-096` 已完成人工审批，3 个试运行题保持待人工抽检。
- 历史材料中的“0/5”“五题试运行”是早期规划口径，不是当前 MVP 进度或完成门槛。
- 每批 5 题仅用于后续 125 题规模化批处理，与当前 3 个试运行题不是同一口径。

### 已形成

- 资料摄取、论文事实提取、机制映射、算法假设、证据复核和候选图谱的工程链路。
- 1 个黄金样例与 3 个试运行题均已通过 Schema、引用、语义和正式模型调用的机器验证。
- schema v2 实验计划、Adapter 路由、smoke/full-run、结果账本和计划修订能力。
- 多轮 FashionMNIST 预测编码实验及正式 Stage 3 全数据集 benchmark。
- Stage 3 研究闭环已达到 `accepted_for_writeup`；其结论仅支持已声明的 FashionMNIST 和结构化遮挡边界，不扩展为神经真实性或跨任务普适结论。
- 人类门控、候选知识与正式知识分层、失败/不确定结果保留和证据追溯机制。

### 尚未满足

- 125 个科学问题清单和单题输出协议已经建立，但正式批处理账本、125 份逐题结果和全量汇总文档尚未生成。
- 正式账本已登记 8 条 DashScope/Qwen 调用证据；面向提交包的脱敏截图、调用说明和复核清单仍待收束。
- 不超过 20 页的最终 PDF、稳定测试 API、评审可访问前端入口和代表性输入输出案例尚未收束为提交包。
- 对外流程页面和仓库内脱敏报名模板已统一为固定作品名称；正式提交前仍需对 PDF、API、前端和上传包执行一次全量一致性扫描。
