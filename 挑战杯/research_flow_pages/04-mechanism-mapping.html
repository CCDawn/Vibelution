当前节点规划

本页只展示 04 节点。通过左侧导航可进入其它节点页。

目标

建立从神经科学机制到神经网络设计空间的可审查映射。

输入

  • neuro_mechanism
  • 证据等级
  • 算法相关性说明

处理动作

  • 映射到注意力、记忆、反馈、预测误差、稀疏激活、动态路由等抽象。
  • 明确哪些是论文事实，哪些是本项目算法推断。
  • 为每个映射标记 over_analogy 风险。

输出物

  • mechanism_mapping_YYYYMMDD_NNN.json
  • NeuroMechanism maps_to MechanismMapping

风险

  • 过度类比
  • 抽象过宽
  • 不可转为实验计划

未决事项

  • 后续是否补独立 mechanism_mapping.schema.json 文件。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态首版候选映射已生成
记忆平台只进入 CandidateStore 草稿区；正式 Team Knowledge/RAG/知识图谱仍等待后续证据复核和知识治理。
图谱同步候选图谱可展示 NeuroMechanism maps_to MechanismMapping，正式图谱同步仍由审批门禁控制。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态mechanism_mapping_candidate
功能岗位Mechanism Mapping Agent
Agent 状态建议新增专门 Agent；也可先由 Neuro Mechanism Extraction Agent + Algorithm Hypothesis Agent 串联承担
进入条件neuro_mechanism 已有证据链和不确定性说明。
退出条件每个映射标出 fact、inference 和 over_analogy 风险。
审核门禁确认映射没有把类比包装成论文事实。

本步操作

映射到注意力、记忆、反馈、稀疏激活、动态路由等计算抽象。

本地研究模型用法

本地 9B 模型适合做多方案机制映射；必须拆分 factLayer、inferenceLayer 和 overAnalogyRisk。

所需功能

  • 机制到计算抽象映射
  • fact/inference 分层
  • over_analogy 风险标记
  • 映射链路 links

工具/平台能力

  • knowledge_rag_retrieve_tool
  • research_knowledge_query_tool

功能缺口

mechanism_mapping 最小输出契约与类比风险门禁已接入 CandidateStore；跨候选断链检测和独立 schema 文件仍待补。

失败回退

缺 factLayer/inferenceLayer/engineeringImplication，或高类比风险未标记 over_analogy_risk 时进入 mapping_needs_revision，不进入 algorithm_hypothesis。
