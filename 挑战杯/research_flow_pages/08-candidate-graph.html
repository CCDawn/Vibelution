Research Flow Node 08

资料关系整理预览

让团队先看到研究链路，但不污染正式知识图谱。

Teams 可视化已接入Candidate Graph Preview Agent独立计划页
输入CandidateStore candidates / paperNoteIds / neuroMechanismIds / mechanismMappingIds
动作读取 candidate_only、ready_for_candidate_graph、excluded 状态。
输出candidate_graph 候选快照 / Teams 资料关系整理面板
记忆/图谱只展示资料关系整理；正式图谱同步必须等 ingested。

当前节点规划

本页只展示 08 节点。通过左侧导航可进入其它节点页。

目标

可视化候选中的 Paper、Mechanism、Mapping、Hypothesis、Review 链路。

输入

  • CandidateStore candidates
  • paperNoteIds / neuroMechanismIds / mechanismMappingIds
  • 候选状态

处理动作

  • 读取 candidate_only、ready_for_candidate_graph、excluded 状态。
  • 展示 supports、maps_to、inspires、reviewed_by 等候选边。
  • 突出缺失链接和断裂证据链。
  • Teams 工作台科研流程面板可读取 latest candidate_graph，并用 SVG 小图展示节点、边、断链和未审节点。
  • 刷新图谱按钮复用 POST candidate-graph，只生成 candidate_only 快照，不写正式 Team Knowledge、RAG 或正式图谱。

输出物

  • candidate_graph 候选快照
  • Teams 资料关系整理面板
  • missingLinks 断链报告
  • unreviewedNodes 未审节点清单

风险

  • 资料关系整理被误读为正式知识
  • links 指向不存在对象

未决事项

  • 是否仍需要导出独立 candidate_graph.json，或保持前端直接读取 CandidateStore graph payload。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态Teams 可视化已接入
记忆平台资料关系整理只进入 CandidateStore 草稿区，不进入正式 RAG。
图谱同步只展示资料关系整理；正式图谱同步必须等 ingested。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态candidate_graph_visible
功能岗位Candidate Graph Preview Agent
Agent 状态后端/API 已可生成资料关系整理快照；Teams 工作台绑定独立 candidate_graph Agent，并把 agentProcess 显示到当前步骤过程页。
进入条件CandidateStore 中存在 paper_note / neuro_mechanism / mechanism_mapping / algorithm_hypothesis 等候选。
退出条件candidate_graph 候选快照能列出 nodes、edges、missingLinks、unreviewedNodes 和 officialBoundary，并能在 Teams 科研流程面板可视化查看。
审核门禁确认资料关系整理只作预览，不作为正式知识证据使用。

本步操作

由 candidate_graph Agent 从已通过筛选的 source_manifest 与后续候选链路重建候选关系；Teams 面板可请求最新 candidate_graph，渲染 evidence -> candidate 的阅读向箭头，并在过程页展示输入、输出和下一步。

所需功能

  • candidate_graph 候选快照生成
  • 候选节点/边预览 payload
  • 断链报告
  • 未审节点清单
  • 候选/正式边界标识
  • Teams SVG 资料关系整理面板
  • candidate_graph Agent 过程追踪

工具/平台能力

  • /api/teams/{teamId}/workflow-orchestration/candidate-graph
  • CandidateStore
  • TeamsRoute 资料关系整理渲染

功能缺口

独立 candidate_graph.json 导出仍待接；首版前端直接读取 CandidateStore graph payload。

失败回退

候选链接指向不存在对象时输出 missingLinks，并把质量状态标记为 broken_links，不允许进入正式同步。
