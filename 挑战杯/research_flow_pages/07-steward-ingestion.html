Research Flow Node 07

知识治理入库

现有知识库管理员 Agent 是固定网关，不新增平行管理员。

已规划Knowledge Steward Agent · agent-knowledge-steward独立计划页
输入ready_for_steward 候选 / sourceFiles
动作检查来源、目标知识域、证据链、评级建议和摄取包。
输出knowledge proposal / rating suggestion
记忆/图谱通过后等待授权审批门禁批准，再进入正式知识图谱。

当前节点规划

本页只展示 07 节点。通过左侧导航可进入其它节点页。

目标

把 ready_for_steward 候选整理为记忆平台 proposal、评级建议和摄取包。

输入

  • ready_for_steward 候选
  • sourceFiles
  • review 字段
  • 目标知识域

处理动作

  • 检查来源、目标知识域、证据链、评级建议和摄取包。
  • 使用 knowledge proposal / ingestion / rating suggestion 相关工具。
  • 遇到证据不足时返回 steward_needs_revision。

输出物

  • knowledge proposal
  • rating suggestion
  • steward_recommended 状态

风险

  • 绕过审核
  • 目标知识域错误
  • 把候选图谱误当正式事实

未决事项

  • 正式审核角色除用户外是否还需要 Team owner/lead。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态已规划
记忆平台知识治理 Agent 边界是 proposal_and_rating_suggestion_only，不绕过正式审核。
图谱同步通过后等待授权审批门禁批准，再进入正式知识图谱。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态steward_recommended
功能岗位Knowledge Steward Agent / agent-knowledge-steward
Agent 状态固定现有知识管理员 Agent；边界 proposal_and_rating_suggestion_only
进入条件review.decision=approve_for_steward，且 sourceFiles、review 字段存在。
退出条件摄取包包含 targetDomain、sourceTrace、riskSummary、ratingSuggestion、approvalRequired=true。
审核门禁知识治理 Agent 只给建议；正式应用 proposal/rating/入库必须等待授权审核。

本步操作

知识治理 Agent 生成 knowledge proposal、rating suggestion 和 ingestion pack。

本地研究模型用法

本地 9B 模型只能生成 proposal/ingestion pack 草稿，正式建议仍由 Knowledge Steward Agent 检查。

所需功能

  • 知识治理任务读取
  • knowledge proposal
  • rating suggestion
  • ingestion pack
  • targetDomain 选择

工具/平台能力

  • knowledge_governance_tasks_tool
  • knowledge_steward_workbench_tool
  • knowledge_steward_recommendations_tool
  • knowledge_proposal_tool
  • knowledge_ingestion_tool
  • knowledge_rating_suggestion_tool

功能缺口

需要 steward_ingestion_pack 格式和知识治理 Agent 与证据复核 Agent 的交接规则。

失败回退

证据链不足或目标知识域错误时返回 steward_needs_revision。
