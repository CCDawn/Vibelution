Research Flow Node 07

知识治理入库

steward_pack_draft 先进入 CandidateStore 草稿包，正式入库仍由审批门禁控制。

M5 草稿包门禁已落地Knowledge Steward Agent · agent-knowledge-steward独立计划页
输入review_record 候选 / algorithm_hypothesis 候选
动作校验 candidateIds、targetDomain、sourceTrace、riskSummary、proposalPayload、ratingSuggestion。
输出steward_pack_draft 候选 / steward_needs_revision 状态
记忆/图谱不写正式知识图谱；候选图谱只能作为 sourceTrace/candidateGraphId 追溯来源。

当前节点规划

本页只展示 07 节点。通过左侧导航可进入其它节点页。

目标

把待治理候选整理为带 sourceTrace、proposalPayload、ratingSuggestion 和 approvalRequired=true 的摄取草稿包。

输入

  • review_record 候选
  • algorithm_hypothesis 候选
  • candidate_graph 快照
  • 目标知识域

处理动作

  • 校验 candidateIds、targetDomain、sourceTrace、riskSummary、proposalPayload、ratingSuggestion。
  • 强制 approvalRequired=true，禁止 officialSync、applyNow 或 writeOfficialGraph 等立即正式写入意图。
  • 合格草稿进入 steward_pack_draft；证据链或审批边界不合格进入 steward_needs_revision。

输出物

  • steward_pack_draft 候选
  • steward_needs_revision 状态
  • approval gate 待接入

风险

  • 绕过审批门禁
  • 目标知识域错误
  • 把 ingestion pack 草稿误当正式入库记录

未决事项

  • 下一步如何把 steward_pack_draft 映射到现有 knowledge proposal / ingestion tool 的待审对象。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态M5 草稿包门禁已落地
记忆平台只写 CandidateStore；不写正式 Team Knowledge/RAG，等待 Knowledge Steward Agent 和 Ingestion Approval Gate。
图谱同步不写正式知识图谱；候选图谱只能作为 sourceTrace/candidateGraphId 追溯来源。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态steward_pack_draft
功能岗位Knowledge Steward Agent / agent-knowledge-steward
Agent 状态后端草稿包门禁已接入 CandidateStore；正式 knowledge tools 映射待接
进入条件review_record 或候选图谱已给出可追溯 candidateIds，且具备目标知识域。
退出条件合格草稿停在 steward_pack_draft，等待 Knowledge Steward Agent 复核和审批门禁。
审核门禁必须经 Knowledge Steward Agent / Ingestion Approval Gate 确认，不能由科研执行 Agent 或本地模型直接入库。

本步操作

生成带 sourceTrace、riskSummary、proposalPayload、ratingSuggestion、approvalRequired=true 的 CandidateStore 草稿包。

本地研究模型用法

本地 9B 模型只能生成 steward_pack_draft 草稿，正式建议仍由 Knowledge Steward Agent 检查；禁止在输出中请求正式写入。

所需功能

  • sourceTrace 校验
  • proposalPayload
  • ratingSuggestion
  • approvalRequired=true
  • official write 禁止项

工具/平台能力

  • knowledge_governance_tasks_tool
  • knowledge_steward_workbench_tool
  • knowledge_steward_recommendations_tool
  • knowledge_proposal_tool
  • knowledge_ingestion_tool
  • knowledge_rating_suggestion_tool

功能缺口

需要把 steward_pack_draft 映射到现有 knowledge proposal / ingestion tool 的待审对象，并补 official_sync_record。

失败回退

缺必填治理字段、approvalRequired 非 true，或包含 officialSync/applyNow/writeOfficialGraph 时返回 steward_needs_revision。
