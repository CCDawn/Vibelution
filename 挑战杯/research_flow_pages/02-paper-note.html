Research Flow Node 02

生成 paper_note

把资料转成可审查的论文/资料笔记候选。

自动草稿桥已接入Paper Note Extraction Agent独立计划页
输入资料清单 / sourceExtraction.pageAnchors
动作从 sourceExtraction.excerpt/pageAnchors 组装 sourceRefs、evidenceRefs 和 excerpt。
输出paper_note_YYYYMMDD_NNN.json / 候选状态 draft
记忆/图谱进入候选图谱，可被 neuro_mechanism links 引用。

当前节点规划

本页只展示 02 节点。通过左侧导航可进入其它节点页。

目标

从资料中提取背景、方法、关键发现、局限和引用位置。

输入

  • 资料清单
  • sourceExtraction.pageAnchors
  • PDF 页码
  • 论文片段
  • 补充备注

处理动作

  • 从 sourceExtraction.excerpt/pageAnchors 组装 sourceRefs、evidenceRefs 和 excerpt。
  • 调用 Local Research Worker Model 生成 summary、keyFindings、methods、limitations。
  • 通过 CandidateStore 校验 citation/page anchor，合格时进入 paper_note_draft。
  • 回写 source candidate 的 paperNoteDrafts trace，保留 uncertainty，避免把摘要写成确定事实。

输出物

  • paper_note_YYYYMMDD_NNN.json
  • 候选状态 draft
  • Paper -> PaperNote 关系

风险

  • 摘要过度压缩
  • 缺页码
  • 把作者假设当成实验结论

未决事项

  • 长论文拆分为多个 paper_note 的 chunk 策略仍待规划。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态自动草稿桥已接入
记忆平台仍属于候选知识，不进入正式 RAG。
图谱同步进入候选图谱，可被 neuro_mechanism links 引用。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态paper_note_draft
功能岗位Paper Note Extraction Agent
Agent 状态自动草稿桥已接入 / 长文 chunk 策略待规划
进入条件资料已登记且 allowedForAnalysis=true。
退出条件关键发现能回指 sourceFiles、页码或章节；uncertainty 不为空时显式保留。
审核门禁必要时确认摘要是否保守、是否遗漏关键章节。

本步操作

生成 paper_note，抽取 summary、keyFindings、methods、limitations 和 citation anchors。

本地研究模型用法

本地 9B 模型适合按章节或 chunk 生成 paper_note 草稿；32k 内保留 18k-22k 原文证据和输出预留；invoke 会自动登记模型调用证据。

所需功能

  • PDF/资料摘录
  • paper_note 候选 JSON 生成
  • citation anchors
  • uncertainty 字段

工具/平台能力

  • research_knowledge_query_tool
  • sourceExtraction.excerpt
  • 本地研究模型 task/output API
  • /api/teams/{teamId}/workflow-orchestration/official-model-evidence/status
  • /api/teams/{teamId}/workflow-orchestration/candidates/{candidateId}/paper-note-draft

功能缺口

paper_note schema 与页码引用校验已接入 CandidateStore；本地 PDF 页码摘录已可由 source-extraction 提供，并已接入自动 paper_note 草稿桥；长文拆分和多草稿合并仍待接。

失败回退

缺页码、缺来源或摘要过度推断时退回 paper_note_needs_revision。
