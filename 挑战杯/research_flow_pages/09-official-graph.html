Research Flow Node 09

正式知识图谱同步

只有审核入库后的知识进入正式图谱 trace 与 RAG。

已规划Knowledge Platform独立计划页
输入approved_to_ingest 候选 / 正式 KnowledgeItem
动作将 official_pending 转为 official_synced。
输出正式知识图谱 trace / 正式 RAG 可检索上下文
记忆/图谱正式图谱 trace 必须能追溯到 sourceTrace、candidateIds、reviewRecordIds 和正式 KnowledgeItem。

当前节点规划

本页只展示 09 节点。通过左侧导航可进入其它节点页。

目标

将 ingested 知识同步到 Team Knowledge、正式 RAG 和 KnowledgeItem officialResearchGraph。

输入

  • approved_to_ingest 候选
  • 正式 KnowledgeItem
  • 知识治理建议

处理动作

  • 将 official_pending 转为 official_synced。
  • 生成正式 supports、maps_to、inspires、approved_for_ingestion 边。
  • 保留 sourceFiles 和 review 追溯链。

输出物

  • 正式知识图谱 trace
  • 正式 RAG 可检索上下文
  • officialKnowledgeItemId
  • officialResearchGraph

风险

  • 候选误同步
  • sourceFiles 丢失
  • 正式图谱缺审核记录

未决事项

  • 是否在 Memory Graph 详情栏增加 officialResearchGraph 专用摘要。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态已规划
记忆平台只同步 ingested 内容，正式图谱 trace 挂在 KnowledgeItem metadata 上。
图谱同步正式图谱 trace 必须能追溯到 sourceTrace、candidateIds、reviewRecordIds 和正式 KnowledgeItem。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态official_synced
功能岗位Ingestion Approval Gate + Knowledge Platform
Agent 状态授权审批门禁已接入 Team Knowledge review/apply、KnowledgeItem metadata patch；平台负责正式 KnowledgeItem 的读取、RAG 检索和 Memory Graph 展示
进入条件授权审批门禁已批准 pending RefinementProposal。
退出条件knowledgeItemIds、ratingSuggestionMigration、officialResearchGraph、ragStatus、graphStatus、reviewedByAgentId 和 officialSyncRecord 均已记录。
审核门禁必须通过授权审批门禁批准 ingestion pack。

本步操作

复用 Team Knowledge review/apply 创建 KnowledgeItem；旧 proposal 级 ratingSuggestion 标记 applied，新 KnowledgeItem 级 ratingSuggestion 保持 pending 等待评级审阅；sourceTrace/candidateIds 被翻译为 officialResearchGraph 正式边；RAG 通过 reviewed Team Knowledge 检索。

所需功能

  • 正式审核确认
  • 正式 KnowledgeItem 创建/同步
  • KnowledgeItem rating review
  • officialResearchGraph
  • RAG 可检索
  • official_sync_record
  • Memory Graph 可见

工具/平台能力

  • knowledge_query_tool
  • knowledge_rag_retrieve_tool
  • Team Knowledge 审核/应用流程（平台能力）

功能缺口

ratingSuggestion 自动迁移到 KnowledgeItem 待审评级已接入；正式 supports/maps_to/inspires/approved_for_ingestion 边已接入 officialResearchGraph，并可在 Memory Graph 画布展开。后续可补专用摘要与筛选。

失败回退

未批准时停留在 candidate_graph_visible，不进入正式知识库。
