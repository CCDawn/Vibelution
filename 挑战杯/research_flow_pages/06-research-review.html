Research Flow Node 06

科研审稿

在交给记忆平台前先做领域与工程风险过滤，并把返工/拒绝/待转移纳入团队协调队列和沟通建议。

prefilter 与协调队列已落地Evidence Review Agent独立计划页
输入paper_note / neuro_mechanism
动作填写 candidateIds、checklist、comments、requiredChanges、riskFlags、needsDecision。
输出review_record 候选 / review_prefiltered 状态
记忆/图谱候选图谱可展示 reviewed_by、needs_revision 边；rejected 归档候选从可推进图谱中隔离，并在 summary 中计数。

当前节点规划

本页只展示 06 节点。通过左侧导航可进入其它节点页。

目标

先用 review_record 候选记录证据、类比、可测性和成本风险；返工走 transfer returned，拒绝进入 rejection_archive。

输入

  • paper_note
  • neuro_mechanism
  • algorithm_hypothesis

处理动作

  • 填写 candidateIds、checklist、comments、requiredChanges、riskFlags、needsDecision。
  • 标记 weak_evidence、missing_citation、over_analogy、not_testable 等风险。
  • 禁止本地模型写最终 decision；高争议候选进入人工/门禁决策。
  • Research Coordination Agent 可将 needs_revision 转移回最小上游节点，或将 rejected 候选归档到 rejection_archive。
  • GET coordination/status 只读聚合 pendingTransfers、needsRework、blocked、stewardship 和 active 队列，并为每个队列项生成 communicationBrief。

输出物

  • review_record 候选
  • review_prefiltered 状态
  • review_needs_revision 状态
  • transfer returned/rejected 记录
  • rejection_archive
  • coordination_status

风险

  • 证据复核 Agent 只做形式审核
  • 缺少明确退回项
  • 风险标记不可复用

未决事项

  • 是否需要为 Evidence Review Agent 增加专用 decision API，而不是继续复用通用 transfer decide。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态prefilter 与协调队列已落地
记忆平台审稿记录仍是候选工作区内容；rejected 候选只保留归档证据，不进入正式记忆。
图谱同步候选图谱可展示 reviewed_by、needs_revision 边；rejected 归档候选从可推进图谱中隔离，并在 summary 中计数。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态review_ready
功能岗位Evidence Review Agent
Agent 状态review prefilter 与返工/拒绝 transfer 闭环已接入；最终裁决仍复用通用转移裁决
进入条件paper_note、neuro_mechanism、algorithm_hypothesis 字段完整。
退出条件review_record 候选含 candidateIds、checklist、comments、requiredChanges、needsDecision，状态为 review_prefiltered。
审核门禁高争议候选、拒绝重要候选或放行弱证据候选时进入审核门禁确认。

本步操作

证据复核 Agent 检查证据、类比、可测性、成本和重复假设。

本地研究模型用法

本地 9B 模型只做 review prefilter，产出 riskFlags、requiredChanges 和 needsDecision，不写最终 review.decision。

所需功能

  • 证据审查
  • 类比风险审查
  • 可测性/成本审查
  • review_record 生成
  • 返工转移
  • 拒绝归档

工具/平台能力

  • research_knowledge_query_tool
  • knowledge_rag_retrieve_tool

功能缺口

rejectionArchive 规则和 returned/rejected 转移已接入；后续可补 Evidence Review Agent 专用 decision API 和 riskFlags 枚举。

失败回退

缺 checklist/comments/needsDecision，或本地模型写最终 decision 时进入 review_needs_revision；审稿要求返工时 Research Coordination Agent 通过 transfer returned 回到最小上游节点；明确拒绝时 transfer rejected 进入 rejection_archive。
