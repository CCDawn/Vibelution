Research Flow Node 10

实验迭代闭环

把实验与迭代合成一个模板化 Research Loop：按算法模型、仿真模拟、数据集基准、环境探针、资料审查等问题类型切换模板，先登记人工证据和决策，不接沙盒 runner。

Research Loop 模板化流程 API 已接入Research Loop Agent / Experiment Ledger Service独立计划页
输入experiment ResearchStageRound / algorithm_hypothesis
动作GET experiments/status 聚合实验轮次、算法假设候选、计划草稿、baseline/metric/dataset/smoke 缺口。
输出experiment_plan 草稿 / active_baseline_artifact
记忆/图谱Research Loop 是候选流程状态，不创建正式图谱边；正式边仍等待 Knowledge Steward 审批后从 ExperimentResult/KnowledgeItem trace 生成。

当前节点规划

本页只展示 10 节点。通过左侧导航可进入其它节点页。

目标

根据研究问题选择验证模板，记录所需证据、指标、日志和迭代决策；把可推进结论转成下一轮模板建议，而不是自动训练或自动入库。

输入

  • experiment ResearchStageRound
  • algorithm_hypothesis
  • experimentPlan
  • baseline/metric/dataset/smokePlan
  • researchQuestion
  • templateId

处理动作

  • GET experiments/status 聚合实验轮次、算法假设候选、计划草稿、baseline/metric/dataset/smoke 缺口。
  • POST experiments/plan 生成 experiment_plan 草稿，写入 experiment_plans/index.json 并挂回 ResearchStageRound。
  • POST experiments/plans/{planId}/baseline-artifact 登记 active baseline artifact，解除 baseline blocker 并开放 smoke gate。
  • POST experiments/plans/{planId}/smoke-result 登记 smoke 指标、日志和结果路径；passed 才解除 full-run blocker。
  • POST experiments/plans/{planId}/full-run-result 只登记人工 full-run 结果证据；Knowledge Steward 入库请求仍走显式审批边界。
  • GET research-loop/templates 暴露算法模型、仿真模拟、数据集基准、环境探针、深度资料审查、论文结论复核模板。
  • POST research-loop/loops 按 templateId 创建实验迭代 loop，可关联 stageRoundId、planId、candidateIds 和研究问题。
  • POST research-loop/loops/{loopId}/evidence 登记人工证据、指标、artifact/log/source/dataset/environment refs 和 commandPreview。
  • POST research-loop/loops/{loopId}/decision 在证据齐备后登记 promote/repair/more-evidence/reject/writeup 决策，并生成下一轮 iterationProposal。
  • 强制边界：不接沙盒 runner，不触发训练 runner，不自动写 ExperimentResult，不自动写正式 Team Knowledge/RAG/official graph。

输出物

  • experiment_plan 草稿
  • active_baseline_artifact
  • smoke_result
  • full_run_result 手工账本
  • research_loop
  • evidenceRecords
  • decision
  • iterationProposal
  • readinessChecklist

风险

  • 计划草稿被误认为已训练
  • commandPreview 被误当已执行
  • 模板证据缺口没有补齐就推进迭代
  • baseline 不公平

未决事项

  • TeamsRoute 前端总控面板等待当前 source collection dedupe claim 释放后接入；沙盒 runner 明确后置，不属于当前阶段。
