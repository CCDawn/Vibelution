资料进入工作区

建立稳定证据源，并把本地 PDF 转成可引用的页码锚点。

输入用户提供的论文/PDF / 赛题 PDF
动作登记文件路径、资料类型、页码范围和来源可信度。

记忆/图谱可作为候选图谱的 Paper source 节点，不进入正式知识图谱。

当前节点规划

本页只展示 01 节点。通过左侧导航可进入其它节点页。

目标

把用户提供的论文、PDF、赛题文件和补充资料登记为可追溯输入。

输入

  • 用户提供的论文/PDF
  • 赛题 PDF
  • 补充资料
  • 挑战杯工作区路径

处理动作

  • 登记文件路径、资料类型、页码范围和来源可信度。
  • 对本地 PDF source_manifest 运行 source-extraction，计算 sha256 并生成 pageAnchors 与 excerpt。
  • 区分允许分析、暂不分析、需要用户确认的资料。
  • 保留原始文件，不在资料入口阶段改写内容。

输出物

  • 资料清单
  • sourceFiles 引用
  • sourceExtraction.pageAnchors
  • Paper 原始来源节点

风险

  • 资料来源不明
  • PDF 抽取失败
  • 联网搜索结果混入第一版

未决事项

  • 长 PDF 是否需要自动分批抽取与章节级拆分规则。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态第一轮资料搜集已跑通
记忆平台不进入正式记忆库；只作为后续 paper_note 的 sourceFiles。
图谱同步可作为候选图谱的 Paper source 节点，不进入正式知识图谱。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态source_registered
功能岗位Source Intake Agent
Agent 状态可复用通用 data-processing assignment / source-extraction 后端已接入；Teams 资料搜集执行台和三阶段启动台已接入
进入条件用户提供 PDF、论文、赛题或补充资料；文件可在挑战杯工作区定位。
退出条件每个知识搜集轮次有 stageRoundId、roundNumber、teamMemoryRecord、coordinationContract、sourceRunIds、dataSearchPlanRef、planned queries、assignedQueries 和 resultWritebackContract；每个资料项先有 DataRecord/sourceRef/rawLocation/title/qualitySignals/collectionTrace，再有 source_manifest 的 id、path、type、allowedForAnalysis、sha256、pageScope 和 sourceExtraction.pageAnchors。
审核门禁确认资料允许分析、来源可信度和是否纳入本轮。

本步操作

用户在 ai科学研究团队右侧顶部点击“启动知识搜集”或“开启新一轮”，stage-rounds/start 创建或续用 ResearchStageRound，并复用 source-collection run 建立 DataProcessingRun；系统基于 topic/goal/scope/querySeeds 生成 searchPlan、queries、roleAssignmentInputs 和 resultWritebackContract，让 data_discovery/source_acquisition/content_extraction/source_quality 等功能 Agent 领取带 assignedQueries 的 CollectionAssignment、提交 CollectionOutput。执行台支持手工回写一条 CollectionOutput，随后自动通过 Team workflow 导入桥把新 DataRecord 幂等转成 source_manifest 候选。对本地 PDF 运行 source-extraction，计算 sha256、生成 pageAnchors/excerpt，不改写原文，不自动混入联网资料。

本地研究模型用法

本地 9B 模型适合做标题/摘要/片段初筛，输出 relevanceScore、topicTags、excludeReason，不直接决定正式纳入。

所需功能

  • ResearchStageRound 建立
  • 三阶段启动台一键进入知识搜集
  • DataProcessingRun 建立
  • DataSearchPlan/querySeeds 搜索计划
  • CollectionAssignment 资料搜集任务
  • assignedQueries 角色分配
  • Teams 启动搜集批次
  • Teams 查看 run/assignment/query 状态
  • 手工 CollectionOutput 回写
  • DataRecord 通用记录
  • DataRecord 自动导入 source_manifest
  • 本地资料登记
  • source_manifest 写入
  • 文件路径/页码/来源可信度记录
  • 本地 PDF sha256/pageAnchors/excerpt 抽取
  • 可选 research_knowledge_query_tool 查重

功能缺口

科研三阶段启动台、资料搜集阶段轮次、资料搜集批次启动、DataSearchPlan/query seed 契约、通用资料搜集 assignment/output、Teams 执行台和 DataRecord 到 source_manifest 导入桥已接入；真实外部搜索执行器、长 PDF 自动分批、章节识别和非 PDF 资料解析仍待补。

失败回退

资料不足、路径缺失、来源不明、权限不清、抽取失败或解析器不可用时，assignment 标记 returned/partial，挑战杯候选停在 source_needs_confirmation。
