建立稳定证据源，并把本地 PDF 转成可引用的页码锚点。

记忆/图谱可作为候选图谱的 Paper source 节点，不进入正式知识图谱。

当前节点规划

本页只展示 01 节点。通过左侧导航可进入其它节点页。

目标

把用户提供的论文、PDF、赛题文件和补充资料登记为可追溯输入。

输入

  • 用户提供的论文/PDF
  • 赛题 PDF
  • 补充资料
  • 挑战杯工作区路径

处理动作

  • Data Intake Coordinator Agent 定义搜集范围、批次验收标准、去重规则和返工路径。
  • Data Discovery Agent 从搜索工具、工作区文件、历史记忆和已配置目录发现候选资料。
  • Source Acquisition Agent 只登记或获取原始 sourceRef/rawLocation，不改写内容。
  • Content Extraction Agent 对文件/PDF/网页生成 checksum、anchors、excerpt 和 metadata。
  • Source Deduplication Agent 合并重复 URL、文件 hash、标题或近似片段，只保留 trace alias。
  • Source Quality Agent 标记 relevance、credibility、freshness、permission 和风险信号。
  • 登记文件路径、资料类型、页码范围和来源可信度。
  • 对本地 PDF source_manifest 运行 source-extraction，计算 sha256 并生成 pageAnchors 与 excerpt。
  • 区分允许分析、暂不分析、需要用户确认的资料。
  • 保留原始文件，不在资料入口阶段改写内容。

输出物

  • 资料清单
  • sourceFiles 引用
  • sourceExtraction.pageAnchors
  • Paper 原始来源节点

风险

  • 资料来源不明
  • PDF 抽取失败
  • Agent 把发现结果误标为可信来源
  • 联网搜索结果混入未审核资料

未决事项

  • 长 PDF 是否需要自动分批抽取与章节级拆分规则。
  • 通用 data-processing 的 CollectionAssignment 何时替代当前 source_manifest 专用登记。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态source-extraction 已落地
记忆平台不进入正式记忆库；只作为后续 paper_note 的 sourceFiles。
图谱同步可作为候选图谱的 Paper source 节点，不进入正式知识图谱。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态source_registered
功能岗位Source Intake Agent
Agent 状态现有 source-extraction 后端已接入；通用 CollectionAssignment Agent 分工待实现
进入条件用户提供 PDF、论文、赛题或补充资料；文件可在挑战杯工作区定位。
退出条件每个 PDF 资料项都有 id、path、type、allowedForAnalysis、sha256、pageScope 和 sourceExtraction.pageAnchors。
审核门禁确认资料允许分析、来源可信度和是否纳入本轮。

本步操作

由功能 Agent 协作完成发现、获取、抽取、去重、质量评分和 intake review；当前已能建立 source_manifest 记录，并对本地 PDF 运行 source-extraction，计算 sha256、生成 pageAnchors/excerpt，不改写原文，不自动混入联网资料。

本地研究模型用法

本地 9B 模型适合做标题/摘要/片段初筛，输出 relevanceScore、topicTags、excludeReason，不直接决定正式纳入。

所需功能

  • Data Intake Coordinator 范围定义
  • Data Discovery 候选发现
  • Source Acquisition 原始 sourceRef/rawLocation 登记
  • Content Extraction checksum/anchors/excerpt 抽取
  • Source Deduplication 去重别名
  • Source Quality 可信度/权限/风险信号
  • source_manifest 写入

工具/平台能力

  • web_search_tool（待按 Agent ToolPolicy 授权）
  • research_knowledge_query_tool
  • /api/teams/{teamId}/workflow-orchestration/candidates/{candidateId}/source-extraction
  • /api/data-processing/runs/{runId}/collection-assignments（待实施）

功能缺口

本地 PDF 页码锚点提取已接入 CandidateStore；长 PDF 自动分批、章节识别和非 PDF 资料解析仍待补。

失败回退

路径缺失、来源不明、权限不清、抽取失败或解析器不可用时停在 source_needs_confirmation。
