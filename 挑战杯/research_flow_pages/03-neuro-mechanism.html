当前节点规划

本页只展示 03 节点。通过左侧导航可进入其它节点页。

目标

形成带证据链的神经机制卡片。

输入

  • paper_note
  • 支持 claim
  • 实验现象
  • 脑区/认知功能线索

处理动作

  • 提取 mechanism.description、brainSystems、cognitiveFunctions。
  • 把 experimentalPhenomena 和作者解释分开记录。
  • 为每个 mechanism evidence 绑定 paperNoteId 和 confidence。

输出物

  • neuro_mechanism_YYYYMMDD_NNN.json
  • PaperNote supports NeuroMechanism

风险

  • 弱证据泛化
  • 神经术语误读
  • 缺少不确定性说明

未决事项

  • 是否需要外部神经科学专家复核机制名称。

记忆与图谱边界

区分候选工作区、知识治理 Agent、正式 Team Knowledge 和正式知识图谱。

候选状态已规划
记忆平台候选机制必须经过证据复核 Agent 和知识治理 Agent 治理后才能入库。
图谱同步候选图谱边：paper_note supports neuro_mechanism。

可跑通节点契约

这一块只覆盖知识搜集、筛选和入库 MVP，不涉及实验训练或交付实现。

状态mechanism_candidate
功能岗位Neuro Mechanism Extraction Agent
Agent 状态需要专门神经机制分析 Agent 或 research_deep 绑定该职责
进入条件paper_note 至少有一个可追溯 keyFinding。
退出条件每个 mechanism 有 evidenceRefs、confidence、brainSystems/cognitiveFunctions 或明确 unknown。
审核门禁遇到神经术语不确定或证据弱时进入领域复核门禁。

本步操作

提取 neuro_mechanism，把实验现象、作者解释和本项目理解分开。

本地研究模型用法

本地 9B 模型适合抽取 neuro_mechanism 候选和风险标记；弱证据必须写 weak_evidence。

所需功能

  • 神经机制抽取
  • 实验现象/作者解释/项目理解分离
  • evidenceRefs
  • confidence

工具/平台能力

  • research_knowledge_query_tool
  • knowledge_rag_retrieve_tool（只查正式背景知识）

功能缺口

neuro_mechanism 最小 schema 与术语风险门禁已接入 CandidateStore；脑区/认知功能词表和证据强度评分规则仍待补。

失败回退

证据弱或术语不确定时必须标记 weak_evidence / terminology_uncertain；缺失风险标记时进入 mechanism_needs_revision，不进入机制映射。
