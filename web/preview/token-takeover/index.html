E · 行高与圆角分析（行高可切换演示，圆角仅分析）

行高分析
  • 原生 text-* 自带 v4 配对行高：xs 1.3333 / sm 1.4286 / base 1.5 / lg 1.5556 / xl 1.4。
  • tokens.css 的 --vui-font-* 只定义字号，不带行高；配对行高存在于语义角色层（--vui-type-*-line）。
  • 生产 @theme inline 的 text-vui-* 槽位也未配 --line-height → text-vui-* 只改字号，行高继承。
  • 默认（size-only）接管：仅重定义 --text-* 字号。原生行高是 ratios（如 sm=calc(1.25/0.875)），会跟随新字号 等比缩放 → 四个零位移档行高像素级不变；唯一变档 text-xl 行高 28px→26.6px（比值 1.4 不变）。
  • 可选「行高配对」模式（勾选演示）：--text-*--line-height 指向 vui 语义档（xs/sm→tight 1.25、base→readable 1.58、lg→snug 1.375、xl→tight 1.25），与语义角色一致，但存量行高变化 −0.08 ~ −0.18（base +0.08）， 视觉差异明显，需集成阶段单独决策。
圆角槽位分析（仅分析，不实施）
  • Tailwind v4：rounded(sm)=4px、md=6px、lg=8px、xl=12px、2xl=16px、3xl=24px；rounded-full 不经变量。
  • vui：--radius-control 8px、--vui-radius-soft 10px、--vui-radius-panel-soft 12px（panel/card 同值）。
  • 可零位移接管：rounded-lg→--radius-control（8=8）、rounded-xl→--vui-radius-panel-soft（12=12）。
  • 不可零位移接管：rounded(4)/rounded-md(6)/rounded-2xl(16) 无对应 vui 槽位（最近 8/8/12，位移 +4/+2/−4px）， 建议维持原生或先补 4/6px vui 微圆角档再评估。结论：圆角只宜做「lg/xl 两档部分接管」。

机制说明：Tailwind v4 将 text-sm 编译为 font-size: var(--text-sm)，槽位默认值发布在 :root；本预览用 .takeover-scope（右列钉住）与 html[data-takeover]（全页）在更近的祖先上重定义同一自定义属性，即等价于集成阶段在 @theme inline 重定义槽位的效果。cn()（web/src/components/vui/lib/cn.ts）是纯字符串拼接、未用 tailwind-merge， 槽位重定义不改变任何 class 合并行为。
