# 个人助理工作台与桌面聊天预览

状态：待用户确认。只包含隔离预览，未修改正式路由、角色设置或 Session 核心。

## 界面契约

- 工作台：角色在左栏、原生会话在中间、紧凑平台概览在右栏。角色只在桌面模式移出工作台。
- 右栏：顶部常用管理入口和状态条始终可见；默认只显示需关注事项；会话和智能体分开查看，支持搜索、筛选与每页八条。其余四个管理入口由“更多管理”保留。
- 桌面模式：点击桌面角色打开约 400 × 530 的聊天小窗，只含身份顶栏、消息、输入、附件入口与发送。收起聊天保留角色，返回完整工作台有单独入口。
- 正式实现沿用同一个个人助理身份与原生 Session；模型、工具审批、消息与流式输出继续由原生链路拥有，不建立第二份会话或转录。

## 角色状态与动作

- 左栏和桌面使用同一套只读状态映射，复用现有 `PetActivity.animationState` 与原生角色状态接口：思考、阅读、工具、验证、回复、待确认、异常、完成与空闲。
- 预览页“状态演示”可以逐项切换，状态文案、右栏计数和角色动作一并变化。工作状态保持到下一次权威状态变化；新消息/完成只播放 1.4 秒动作，随后恢复待机，未读徽标保持到查看。
- 正式接入时待确认优先于近期异常，之后才是未读提示、进行中的任务、短暂完成反馈与空闲；较低优先级提示保留徽标，不覆盖更重要的动作。
- 新消息必须来自实际 Agent 消息事件，按 Session + 消息事件 ID 去重；不以 `updatedAt`、轮询返回时间、切换窗口或抓取到历史内容作为新消息。当前公开 PetActivity 没有未读消息字段，需复用真实消息事件源补齐只读投影。
- 断连显示状态暂不可用，不伪装成正在工作；启用减少动态效果时，保留静态状态和未读徽标。
- 本预览的状态选择与动作计时只用于演示，没有订阅实时平台事件。正式状态闭环与重复提醒防护仍需在批准后的实现中验证。

## 预览边界

- 角色复用现有 `WhaleRigCharacter`，本地动画资源照常加载；个人助理语言配置使用预先填充的模拟数据。
- 124 个会话、51 个智能体及关注事项均为确定性模拟数据，不代表当前平台实时状态。
- 管理入口只给出预览反馈，不跳转或调用真实写操作。
- 聊天消息只保存在页面状态，模拟回复；未连接真实模型、工具审批、操作系统透明窗口、拖动与跨进程切换。
- 预览页上方可切换工作台/桌面、右栏宽度和十种角色状态。

预审通过后再迁移到正式组件，并独立验证桌面窗口尺寸、边界位置、输入焦点和同一 Session 续聊。

## 已验证的预览行为

- 产品 TypeScript 构建检查及包含预览入口的独立类型检查通过。
- 浏览器验证了思考、阅读、执行、验证、回复、待确认、异常映射与角色资源就绪。
- 普通动效下，角色实际收到 jumping 后约 1.4 秒收到 idle；未读提示保留，切换模式不重复提醒，查看后清除并留在工作台。
- 减少动态效果下，新消息保持静态未读提示；桌面小窗输入、模拟回复、收起与恢复可操作。
- 390px 工作台与桌面聊天无横向溢出。以上均为隔离预览证据，未验证实时平台状态、事件去重或原生桌面窗口。
