# Agent 配置布局预览 · 第六版

状态：第六版于 2026-10-13 获用户确认；布局已接入正式 Agent 配置组件。隔离预览及正式组件验证页仍使用安全示例，不写入真实配置。前序研究记录见 RESEARCH.md。

延续移除解释性文案的要求。内容区统一为 640px，标签列 160px，单行选择器、文本框和保存栏共用对齐线。分类直接显示为可横向滚动的导航。模型使用 VPopover 搜索菜单，思考强度使用 VSelect；能力图标放入候选菜单。保留扁平控件和按钮，交互、键盘焦点和禁用原因仍通过现有 VUI API。

## 内容与布局

- 保留 Agent 列表；模型、基本、人物、任务、工具与记忆、委派与监督、运维均有直接入口。普通模型路径仅设置主模型和思考方式。
- 模型选择支持搜索和能力/凭据原因；按当前模型支持的强度渲染参数。5 个可选槽位折叠，未单独绑定时保持现有默认规则。
- 模型保存只提交模型字段；普通配置保存、还原保留待保存模型，模型保存、还原也保留其他草稿。基本配置不再重复编辑模型。
- 真实字段来自 AgentCoreConfigPanel、AgentPersonaProfilePanel、AgentTaskProfilePanel、AgentMemoryPolicyPanel、AgentRuntimePolicyPanel；删除上一版不存在的简介、默认输出、三个工具开关和简化记忆开关。
- 基本配置按基本信息、权限与策略分组，删除重复模型展示和说明入口；人物、任务、记忆、委派均使用单列字段布局。任务的成功标准、交付物和约束直接展示，次要偏好折叠。各页使用相同内容宽度、章节间距和底部保存区域。
- 人物与任务档案独立保存；委派/监督和记忆策略保留各自独立保存边界。
- 五个可选模型槽位放在模型页展开区；压缩字段仍在基本配置。仅变更压缩配置时才写自定义快照，单纯改模型或名称保留原压缩状态。
- 委派并发数为 0–8，深度为 0–4；压缩阈值为 1–100，各计数使用正式下限，非法数值禁用模拟保存。
- 工具列表由工具页维护；记忆共享组与知识库 ACL 按名称选择、添加与移除，存储仍是 ID 数组。真实来源缺少名称时正式实施需保留 ID 回退。
- 同一 Agent 切换标签及切换另一个 Agent 后保留模拟草稿。预览未模拟并发冲突和实际运行生效。
