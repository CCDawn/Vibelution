# 炒股智能体会话优先桌面预览

本目录只提供界面预审，不修改正式 finance route、VUI 组件或真实会话。

- 左栏固定新研究、会话搜索与四组功能入口，只有会话列表独立滚动。
- 全部 14 项功能按研究、行情、资产、资料分组，子功能在主体切换。
- 标题行组合现有 VIconButton ghost 操作，通过 VSplitWorkspace 受控折叠切换左右栏。
- 会话使用 VButton 单行渲染，复用原生 FinanceSessionMenu 与状态映射；归档、恢复、删除只改变当前预览 React 状态。
- 会话、研究步骤、引用、报告、股票名称与代码使用单行布局；长名称省略并提供完整 title，状态图标保留无障碍文本。
- 预览端口 5186；未连接真实行情、模型、报告下载或交易，也不会读取生产凭据。
- 目标桌面视口：1280×800 与 1920×1080。

宽度复用 WORKBENCH_LAYOUT_IDS.finance 与共享 pane persistence，存储属于预览独立 origin。
中间分隔线按钮仅被本目录的作用域样式隐藏。批准前不扩展正式 VUI API 或设计事实源。

## 预审验证（2026-10-07）

- TypeScript：预览 tsconfig 与工作台 `tsc -b` 均通过；VUI 路由和设计登记契约通过。
- 浏览器：1280×800 首屏完整显示 10 条会话；1920×1080 显示全部 16 条。两种窗口无页面横向溢出。
- 14 个子功能均检查单行布局、图标与文字对齐；研究设置标签与选择器同处一行。会话栏 220px / 辅助栏 260px 时无控件溢出。
- 14 个子功能均可从四组访问；辅助栏缩到 260px 后标题操作仍完整可见。
- 已检查会话搜索、长列表选中项、独立滚动、左右栏展开恢复、新研究空态、模拟输入、归档恢复、删除取消与示例删除。
- 调整预览入口后，干净页面无控制台错误；开发期热更新不会再次对同一容器重复 createRoot。

正式 UI 与运行实例尚未变更；布局需用户预审确认后才进入接入阶段。
