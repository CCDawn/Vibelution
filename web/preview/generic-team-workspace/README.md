# 通用团队工作台交互预览

独立入口：`http://127.0.0.1:5237/preview/generic-team-workspace/index.html`。本目录不被正式路由引用，不修改真实团队数据。

## 页面与交互

使用项目 VUI 产品 API、`VCanvasWorkbenchPage` 和共享布局持久化。浅白绿配色，左栏为流程与成员，中间为顺序节点与连线，右栏直接编辑当前节点。设计与运行在同一工作台切换；运行模式显示协作记录、执行状态、人工确认及产物。窄屏将左右栏转换为抽屉，画布独立滚动。

平台没有固定“选题”入口。资料调研、文档审查只是两套可编辑示例；空白流程没有预置业务字段。用户可以修改输入名称、类型、下拉选项和必填条件，新增或调整步骤、负责人及执行要求。运行表单从流程定义生成，每次运行保留启动时的定义快照。

流程图为本预览内的顺序编排视图，根据容器宽度展示 1/2/3 列；连线连接相邻步骤，增删和排序后同步更新。没有改动正式工作流画布 renderer。

## 模拟边界

数据只保留在当前页面，刷新后重置。“保存”仅保存本次预览状态。执行推进、等待人工确认、退回补充、失败重试、停止及文档内容均为前端模拟；没有真实模型调用、Agent 执行、持久化或业务产物。团队成员为演示配置，成员弹窗只读。分支、循环和工具接入尚未实现。预览服务器拒绝 `/api/` 请求。

## 验证与运行

在 `web` 目录运行 Vite，配置文件为 `preview/generic-team-workspace/vite.config.ts`，仅监听 `127.0.0.1:5237`；后台启动遵循项目无控制台窗口规则。构建输出与缓存写入系统临时目录。

预览类型检查使用本目录 `tsconfig.json`。浏览器验证覆盖桌面和 390px 窄屏、动态表单与必填校验、步骤编辑排序与连线、流程切换、历史快照、模拟执行与人工确认、失败重试、停止和产物回读。类型检查、VUI 契约和预览截图不代表正式后端已接通。
