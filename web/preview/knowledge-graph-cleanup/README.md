# 知识图谱清理预览

这是用户已批准的知识图谱界面参考。正式实现接入后，本页直接复用产品图谱引擎；数据仍为隔离演示数据，不连接 API。

默认浅色工作台配合真实三维画布，直接展示十个具体知识标题。标题可切换中文短名与英文名称；知识使用哑光多面体，来源使用小方块，默认连线只表示示例来源映射。默认不显示右侧介绍面板，选点后展开详情，关闭后恢复完整画布。

主题标题、数量、关系切换与显示设置合并为 56px 单行工具栏，删除独立关系栏和重复的关系说明；窄画布自适应为紧凑两行，设置图标保留无障碍名称和原生提示。画布内的侧视、俯视和自动环绕保持原入口。

## 运行

从 `web/` 运行 `npx vite --config preview/knowledge-graph-cleanup/vite.config.ts`，然后访问输出地址下的 `/preview/knowledge-graph-cleanup/`。本目录也提供独立 `tsconfig.json`，可运行 `npx tsc --project preview/knowledge-graph-cleanup/tsconfig.json --pretty false`。

## 可操作范围

- 搜索中文或英文标题、清空搜索、主题导航与未归类空态。
- 知识 / 归属 / 证据层切换，滚轮缩放、侧视、俯视与自动环绕。
- 选择任意知识、保留其他标题、打开来源说明、关闭详情。
- 显示设置中切换中文/英文标题及来源连接。
- 窄屏通过现有 VCanvasWorkbenchPage 打开导航抽屉和底部详情抽屉。

## 模拟边界

全部数据为确定性 mock；中文释义和来源映射是演示内容，不伪装实际知识库记录。画布复用 VMemoryGraphCanvas 与产品 Three.js 引擎，保留 XYZ 布局、透视相机、拖动旋转、平移、滚轮缩放、俯视/侧视与自动环绕。原文读取、审核状态和权限判断未接入。连线不表达支持、反驳或因果关系，空间位置不代表相似度。

仅复用现有 VUI 产品 API、页面 recipe、token 与字体；未新增 V* 或直接导入 renderer。布局记忆沿用 WORKBENCH_LAYOUT_IDS.memory 与 shared pane persistence。

用户已确认此方向，正式页面继续按真实数据与原有权限语义验收。本目录保留为设计参考，不能当作真实业务截图。

正式图谱引擎已接入该外观：知识节点采用哑光二十面体，固定世界方向光产生面间明暗，按距离减弱亮度；来源使用灰蓝小方块，不使用塑料高光。斜视相机和低对比地面网格提供空间参照，网格没有数据刻度，不表示知识的量化坐标。保留原有实例透明度、拾取目标、XYZ 位置与三维遮挡；旋转、缩放和自动环绕仍由原引擎执行。预览专用的源码字符串替换已移除。

标签在旋转、惯性和自动环绕期间逐帧重新避让，优先保留选中项和上一帧可用的位置；发生碰撞时尝试相邻纵向位置，没有空位则暂时收起。标签固定为 32px 高的单行区域，长标题省略显示，悬停原生提示及点选详情保留完整名称。正式实现由原生图谱标签模块维护。
