# Launcher notifications

## LauncherNotificationTopbar

### 功能

Launcher 主窗口右侧顶栏统一承接助理页面的读取异常，恢复后自动移除。它只提供界面投影，不持有 Session、Turn、transcript 或任务的第二份状态。普通聊天与虚拟人会话核心不受影响。

### 适用范围

仅 Launcher 主窗口的助理页面级读取异常；发送、审批和任务执行仍由原有操作 owner 负责。

### 使用方式

`LauncherShell` 在壳内挂载 `LauncherNotificationProvider`，`LauncherTitlebar` 组合 `LauncherNotificationTopbar`；来源通过 `usePublishLauncherNotices` 发布当前读取状态，卸载或恢复时撤回。没有宿主的独立助理浮窗保留原有原地恢复路径。重试始终调用来源最近一次渲染的现有读取回调，避免身份切换后调用旧会话。相同来源的轮询不重复积累通知。

顶栏使用紧凑的图标、摘要和数量，连接类读取异常优先，外观图片失败用中性提醒。点击既有 `VPopover` 打开右对齐详情，复用 `VErrorSummary` 展开技术诊断，以 `VChip` 标明受影响功能、`VButton` 提供对应读取重试。诊断有界，完整错误不占据聊天正文。重试过程禁止重复触发，不自动清除失败状态，不重发消息、审批决定或管理写入。

首次加载失败保留对话区域的短占位，详细错误和恢复动作在顶栏；发送结果未确认、审批决定失败、真正的待授权和待回答事项仍在对应操作附近直接呈现。全局主题动作的结果未确认也保留原操作恢复路径。顶栏无错误时只表达“暂无异常”，不把没有错误误报为已确认连接成功。

### 视觉与交互

沿用 Launcher 的 VUI/shadcn、字重、语义色和密度，不建立新的 VUI primitive、通知服务或操作系统通知。保留原生窗口按钮的右侧空间和拖动边界，通知入口为 no-drag。窄于 520px 时隐藏可见短标签与品牌字样，入口的完整无障碍标签保留；浮层受视口宽高约束，内容可滚动。Escape、外部点击和关闭按钮复用 Radix 的焦点恢复与关闭行为。网页面板复用既有遮挡保护：VUI popover 打开期间撤下原生网页 bounds，关闭后恢复，避免原生网页盖住通知。

恢复事件在对话历史中仍保留真实事件、次数和时间。`conversationSpecialRows` 将 `session_recovery_resumed` 渲染成无背景、无边框的紧凑记录行，不改 Journal、事件顺序或次数，也不影响 CLI 生命周期卡片。

### 验证

覆盖多读取失败合并、外观降级、来源恢复和卸载、身份切换后重试回调、重试锁、真实浮层关闭/焦点、中英文与桌面/窄屏布局。普通会话恢复记录保留原事实，并验证不再使用大卡片背景。
