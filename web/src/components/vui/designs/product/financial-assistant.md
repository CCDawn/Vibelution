### 适用范围

## FinanceRoute

### 功能
`/finance` 是炒股智能体的桌面投研工作台。菜单进入、加载、失败与正式页面共用 `financial-assistant-workspace` 框架。按已确认的 `finance-desktop-tabs` 预览接入真实桌面布局：左栏集中研究、行情、资产、资料功能及助手模型配置，中间顶部切换真实会话，下方显示报告、设置、行情和工具详情；右栏始终挂载原生消息流及 composer。会话搜索、分页、归档、恢复、批量管理与删除集中到顶部「全部会话」，继续复用原生生命周期和归属检查。还没有助手时，入口创建身份、空财报库和会话；打不开时在原布局内给原因和重试。

### 桌面导航与会话标签
`FinanceDesktopNavigation` 复用四组功能定义及 `VRouteLinkButton` 助手配置入口；长模型名和标题保持单行截断，底部配置固定，功能列表独立滚动。`FinanceDesktopSessions` 复用 `VTabs`、`VIconButton` 和 `FinanceSessionMenu`；打开集合只属于当前助手的 UI 状态，缓存已验证的标签摘要，避免旧搜索结果在切换后丢失。关闭标签仅切到相邻会话，至少保留一个标签，不等同于归档或删除。原生操作成功后由生命周期投影移除标签；取消确认、归属变化或失败不移除。选中会话继续由 `useChatRouteSelection` 的 URL 控制。资料/过程旧深链在详细页通过 `VDialog` 继续可达，不另建消息、权限或会话存储。

### 适用范围
本地金融专家的桌面 A 股、港股和美股研究与独立 A 股模拟账户。参考 TradingAgents-CN v3.0 社区版的研究、筛选、自选、报告、记忆、技能、学习与模拟交易信息架构；独立实现，不复制受限前后端源码。真实券商交易与 Pro 专属交易系统不属于这个页面。

### 平面控件视觉
金融工作区与桌面标签预览直接遵循共享 VUI 平面控件基线。按钮、标签页、表单与普通面板使用纯色、细边框与可见键盘焦点；不再维护金融专属的渐变、阴影和焦点覆盖层。主按钮沿用共享 `--vui-primary-face`，保持白字对比度至少 4.5:1；浮层使用共享 overlay 层次。

### 使用方式
复用 `VSplitWorkspace`、`VStateSurface`、`VSkeleton`、`VInput`、`VSelect`、`VTabs`、`VButton`、`VChip`、`VIconButton`、`VSurface` 与 `VRouteLinkButton`。桌面三栏可拖动、折叠，宽度只经 `WORKBENCH_LAYOUT_IDS.finance` 与共享 pane persistence 保存。收起按钮在各栏标题处，收起后在中间标题处恢复；展开时共享 separator 保留拖动与键盘调整。标题、图标、状态、股票代码和引用页码保持单行，长标题截断并提供完整 title，正文与错误正常换行。不做手机版和手机弹窗；1280px 与 1920px 桌面窗口均需验收。Finance 样式来源显式登记在 shell Tailwind 入口；路由代码分块加载与入口初始化均使用同一 frame，避免冷启动闪过通用壳。金融页面隐藏泛化聊天 starter，研究设置提供当前会话的模型选择，助手配置入口保留在左栏底部；原生工具授权入口仍完整保留。
GET 无自动创建；菜单或 `/finance` 这一下才会 POST。POST 幂等且并发串行。
只打开服务端验证 Agent/Session 绑定后返回的 sessionId，经 `useChatRouteSelection.openSession`。
离开入口后，晚到的结果不导航。已归档或身份已改不另建。
公开新闻复用既有 `news_search_tool`，只在本会话作参考；助手判断真伪，不写入财报库，不开启跨团队委派。
原生 `financial_market_snapshot_tool` 允许金融助手在追问中读取公开报价与日/周/月 K 线。研究过程只展示原生 tool call 名称与状态，不另建工具结果流。旧助手仅在服务端投影 `marketToolStatus=upgrade_available` 时展示 `VButton`「启用行情查询」；点击才调用既有幂等 POST，默认策略可升级，禁网、黑名单与自定义工具策略保持原样。写入中或原生研究运行/停止中按钮禁用；失败复用操作错误面，成功刷新助手查询缓存。GET 与页面读取不修改权限。

### 研究记录与输入
研究记录由 `querySessions` 按金融 Agent 查询并核对绑定。历史深链先读取轻量会话元数据，拒绝其他 Agent、已归档及 Companion 身份；不把普通会话套上金融身份。新研究走原生 `createChatSession`，同步 ref 防双击，未知结果重试沿用幂等键，晚到结果经当前路由 CAS 不抢页面。
股票身份来自行情搜索或用户选中的有效自选，历史研究通过原始用户问题恢复股票上下文，不从资料标题推断。分析日期、报告期、研究范围和深度写入实际请求。“开始研究”先写入原生 composer，只有相同草稿已提交到 React 状态且身份一致时才触发原生提交；已有消息时新建原生 Session。不直接调用消息写入 API。Session Journal、SSE、消息流、停止和 HTML 导出仍归原生会话；侧栏投影真实 busy/stopping、工具调用和待授权状态，不模拟多 Agent、阶段或百分比。

### 行情与报告
`FinanceStockOverview` 展示 Tencent 公共报价、来源与时间，保留市场币种、股或手单位和延迟提示；数值不可用显示缺值，不估算。`FinanceStockChart` 使用真实 OHLC、成交量和 MA5/20，支持日/周/月、悬停与方向键；A 股使用前复权，港美股明确未复权；前复权缺失时保留报价并显示 K 线错误，不把未复权数据错标为前复权。
`FinanceResearchReport` 只投影已完成原生 Turn 的 `final_answer`，不把思考、工具返回或未完成内容变成报告。摘要、章节和引用都来自实际回答，Markdown 导出仅导出该回答。报告章节使用 `VTabs`，正文复用原生 Markdown renderer；股票上下文不匹配时显示空态。相同 PDF 的不同页分别保留。`FinanceResearchHistory` 只读原生研究记录，提供关键词、状态筛选与分页。
自选只保存金融 Agent 范围内的有效股票身份，不保存行情、报告、transcript 或第二套会话状态。

### 桌面研究交互补充
沿用已确认的 TradingAgents-CN 单股详情方向和现有三栏布局，使用现有 VUI 控件扩展。图表以 `VTabs` 切换 MA、BOLL、MACD、RSI 及 30/60/全部已加载 K 线，`VIconButton` 向前/向后平移；SVG 只负责金融图形与命中，拖动和 Shift+方向键平移，方向键选择 K 线并播报真实日期/OHLC。指标基于完整已加载数据计算后再裁剪；样本不足显示缺值，不补造历史。股票/周期改变后重置窗口。
报告摘要只保留实际结论文字；纯财务表格直接保留列与单位，完整报告不重复压平摘要。工具“部分结果/备用来源/数据不可用”等语义沿原生字段投影，用警示图标和文字同时说明，不画成普通成功。
报告中心关键词通过原生 `querySessions(q)` 搜索全部本助手研究正文，输入加载、失败重试、空结果与同条件分页保留在原列表。最近研究不受关键词影响。原生 API 没有报告结果筛选契约，结果状态选择器明确只过滤已加载列表，不能把空闲阶段标成已完成。

### 桌面操作可达性
股票准备状态与历史会话分开：切换标的后，标题、概览、过程和报告只展示同一标的；返回研究对话才恢复原会话股票。固定行情头使用紧凑模式，详细行情指标进入中央滚动区，缩短桌面窗口后研究设置与开始操作仍可达。组内导航保持单行横向滚动。
资产组直接提供历史回测；旧复盘回测深链保留。回测与模拟账户隐藏无内容辅助栏，不改写用户保存的栏宽及可见偏好。回测可在上方搜索更换标的，日期、资金、策略优先，费用、撮合及预算折叠到高级设置；阻断原因与字段错误就地展示，预检与启动仍保持原有服务端边界。
报告导航与头部使用紧凑间距，表格为短字段保留最小列宽，长内容正常换行并在表格内横向滚动。

### 财报资料
资料栏使用已绑定的 Agent-owned 财报库，所有条目、trace、source body 请求携带同一 agentId 和 knowledgeBaseId。仅显示有效条目；原文来源另核对 sourceArtifactIds、库归属、PDF 类型、生命周期与过期时间。公司、代码、报告期、版本、页码及链接只来自 sourceRef.financialEvidence，不解析自由标题当事实。无元数据就不显示对应字段，无有效原文就不展示摘录。
摘录使用 React 纯文本；外链只允许无认证信息的 HTTP/HTTPS，打开新窗口使用 noopener。点击报告引用时按有效 sourceRef URL 和 PDF 页码匹配本库来源，定位原文与 `#page=N` 链接；每批最多读取20条有效条目的 trace，未命中再查下一批。读取失败暂停查找，可用现有刷新按钮重试；查完仍未匹配时明确告知，不把无关资料当引用。

## FinanceWorkspaceSidebar

### 功能
会话占据左栏主要空间，独立滚动并按今天、昨天、更早分组。新研究、会话搜索与最近/已归档切换位于列表上方，四组功能入口位于独立窄导航，助手配置固定在导航底部；选中记录自动滚入视野，不反复拉动用户滚动位置。

### 适用范围
金融助手桌面三栏工作台；只呈现当前金融 Agent 的原生 Session 投影，不存第二份 transcript 或生命周期。

### 使用方式
组合 `VButton`、`VInput`、`VDropdownMenu`、`VStateSurface` 与既有 `FinanceResearchHistory compact`、`FinanceSessionMenu`。最近会话关键词调用原生 `querySessions(q)`，分页沿同一关键词；已归档关键词明确只筛已加载记录。当前会话提供直接删除，菜单归档、恢复、删除继续交回 `useFinanceSessionLifecycle`。管理模式收起单行菜单，固定底部提供全选、选中数量、归档/恢复和删除。批量操作逐条验证助手归属并保护运行中会话；删除统一确认，部分失败保留原因，最近批量归档可撤销。主区按当前功能派生分组并用 `VTabs` 展示组内页面，保留全部14项入口，不引入第二份导航状态。紧凑行只保留单行标题、原生结果状态及菜单，完整标题在 title 中显示。

## 对话说明与连接状态

### 功能
正式工作台不设重复产品标题栏，三栏直接接在应用导航下；三栏宽度以当前容器为上限，右栏和报告列表约束最小内容宽度，长文本换行或截断单行标题。行情区域单独显示来源与报价时点。配置与财报管理链接留在对应栏位，避免与原对话说明重复。`/finance` 与 `/chat` 的普通会话窗格都不出现该说明卡；从其他入口（如辅助对话中心）直接打开该助手原生会话时，`FinancialAssistantChatNote` 显示在右侧栏主体顶部，不占用会话正文。普通会话不增加说明。模型未配置时给简短状态，已填写不等于连接已验证。会话原有 HTML 导出保留。

### 适用范围
说明使用完整换行的 `VStateSurface`，不采用两行截断，避免风险说明与配置按钮重叠。右侧栏以同一个 `VSurface` 包含标题工具栏与正文，顶边对齐会话面板；灰色标题区向上连接说明区，工具按钮和配置入口均位于灰色区域内。

只在该助手自己的会话、配置和财报库出现。普通会话、其他 Agent 和虚拟人会话不出现。

### 使用方式
复用 `VStateSurface` 与 `VRouteLinkButton`。列表查询失败时说明不出现，不挡住对话。

### 非职责与反冗余
`FinanceResearchFrame`、`FinanceResearchWorkspace` 与 `FinanceReportLibrary` 共用 `FinanceRoute.styles`，保持加载、工作台与资料栏一致。`FinanceGeneralResearch` 复用知识中心的表单几何，`FinanceWatchlistTable` 与筛选页共用市场表格样式；所有共享消费者在 `vuiImportBoundary` 中逐项登记，不另建重复映射。
不新增 VUI primitive、第二套身份/配置存储、聊天组件、transcript 或 SSE；金融阶段协调复用原生后台任务与生命周期，不另建调度系统。
金融建议与工具沿原生 Agent 权限。股票查询、真实行情与 K 线通过独立只读域 API 校验；模拟账户另用 Agent-owned 账本与明确的虚拟资金接口，不能连接券商或真实资金。

## FinanceGeneralResearch / FinanceTaskCenter

### 功能与使用
通用主题研究使用现有 `VTextarea`、`VInput`、`VSelect` 和 `VButton`，支持行业、政策和投资主题。五级深度写入实际请求；创建独立原生 Session 后，经已提交的原生 composer 启动，没有第二套消息流。主题报告使用原生完成答案，打开历史主题时不套用股票匹配过滤。
任务页组合 `VSurface`、`VChip` 与 `VButton`，展示已加载原生记录的运行、完成、停止、失败和待继续状态；计数对应当前已加载记录，分页继续读取原生索引。空会话占位不算研究任务。

## FinanceMarketExplorer / FinanceWatchlistTable

### 功能与使用
股票筛选使用 `VInput`、`VSelect`、`VButton`、`VDenseTable` 和 `VStateSurface`。结构化条件只作用于已取得的真实股票池，结果明确给来源覆盖数、抓取时点和完整性。自然语言选股只生成原生研究草稿；未运行模型时不显示 AI 选股结果。来源不提供行情日期或市值单位时保留空值并说明，不能把抓取日期当成交日期。
新闻、公告和财务指标使用 `VSurface` 与原文外链，逐项保留来源、发布日或报告期，三块分别呈现错误、缺值与重试。公开数据不冒充已审核 PDF 财报证据。
资料页提供「刷新资料」重新读取三个独立 facet；港股报价 HKD 与财务披露 CNY 不互换，美股 SEC 核验失败或备用财务来源单独标记。已知 US 供应商交易所后缀经严格身份校验后正规化，`BRK.B` 等类别股代码保留。
自选组合既有身份偏好与批量 Tencent 报价，按实际数值排序。单只查询失败保留该行和错误；数字保留元、手和百分比单位，不从股票名称生成数值。
表格只在自身容器横向滚动，各页在中栏纵向滚动；左、右栏继续受共享桌面 pane 约束。

## FinanceDashboard

### 功能
桌面概览把自选实时公开行情、最近研究和批次/计划状态集中呈现。沿用 `VSurface`、`VDenseTable`、`VMetricStrip`、`VChip`、`VButton` 与 `VStateSurface`；加载、空结果与失败分别处理，行情保留来源和读取时间。

### 适用范围
只用于金融助手桌面首页；数据分别来自现有行情、自选、原生研究记录和任务 API。禁止把缺失行情或任务状态补成成功值。

### 使用方式
打开股票进入原生研究，最近研究打开对应 Session，快捷入口导航到选股、报告、任务、模拟账户、组合研究和交易复盘。保持容器可收缩，不增加重复产品顶栏。

## FinanceScreenWorkspace

### 功能
默认提供自然语言选股，示例只使用已支持的价格、涨跌幅、PE、PB、成交量和成交额条件；高级筛选复用 `FinanceMarketExplorer`。提交后创建并运行原生“智能选股”主题 Session，明确要求调用 `financial_market_screen_tool`；候选、来源、抓取时间和覆盖范围只能来自工具实际响应，完成答案进入现有报告与导出流程。
选股请求直接描述筛选条件与报告要求，不套用行业主题研究模板，避免把「智能选股」误解为 AI 产业研究。
智能选股与高级筛选的 AI 研读共用研究可用状态；模型或会话不可用时禁用研究动作，仍允许查看公开筛选结果。

### 适用范围
金融助手桌面选股页。Agent 级预设仅在本机保存筛选条件，最多20组，不存行情或研究内容；不创建第二套对话、结果缓存或执行进度。

### 使用方式
填写或选取条件后点击开始，结果由原生 Agent 运行并写入其 Session。高级条件需要用户点击筛选后读取行情；PB 与成交额范围按 API 的比率和元字段传递，界面成交额输入单位为亿元。

## FinancePaperTrading

### 功能与使用
使用 `VSurface`、`VMetricStrip`、`VDenseTable`、`VInput`、`VSelect` 和 `VButton` 展示虚拟资金、持仓、费用、订单记录和月度复盘。GET 未开账户不建文件，用户明确点击才开设固定100万元模拟资金。下单只传股票、方向、数量、理由和幂等标识，价格由服务端腾讯来源决定；按钮同步防双击，未知结果重试沿用同一标识。
模拟 A 股买入整手、余额、持仓和北京时间自然日 T+1 由服务端检查，页面明确其模拟规则。报价时间、旧价估值和缺值可见，不能把获取时间当新报价。复盘只按真实账本汇总，不生成没有历史持仓估值依据的净值曲线。AI 复盘只在点击后准备包含实际账本的原生草稿。

## FinanceKnowledgeCenter

### 功能
使用 `VSurface`、`VButton`、`VInput`、`VTextarea` 与 `VStateSurface` 组合研究记忆、技能与学习中心。偏好明确保存到同一金融 Agent 的原生 personal memory，原生运行时仍负责加载；GET 不写入。保存与移除只由用户点击，成功后使同一 Agent 查询失效并读回；关闭个人记忆时禁止保存。
私有资料只读取同一 Agent/actor 的原生详情，正文用 React 纯文本；未绑定的其他 Agent 数据不显示。已安装技能按原生命令的 Codex/Agents 来源优先级去重后，仅展示股票相关条目，选取后使用原生 slash command；原生提交时再次解析文件并记录实际版本，不另建技能执行器。技能与记忆文本不覆盖工具和数据权限。
学习中心提供独立编写的五课、八项实践指南与校验题。当前股票练习进入实际原生 composer；课程正文只在选择后显示，切换课程重置答案反馈。

### 适用范围
沿用A股桌面工作台的列表与详情布局；内置方法明确标为“内置研究流程”，不冒充已安装 slash 技能，不改变助手权限。

### 使用方式
技能页默认提供年报核对、新闻辨析、估值、分红、风险、同行比较、筛选及复盘流程。选择流程仅切换详情，“准备研究”按当前股票生成可编辑草稿，不自动发送或调用模型。已安装技能库失败时内置流程仍可使用；无匹配技能时如实显示空状态，不用开发或社交技能填充列表。

## FinanceAnalystTeam / FinanceAnalystTeamInspector / FinancePortfolioResearch

已完成的主助手综合结论排在研究进度之后、五位分析员卡片之前，页面与辅助技术使用相同阅读顺序；进行中、失败与停止的轮次保留分析过程优先。沿用原有卡片与单行操作，不新增页面壳或控件。

### 功能与使用
分析员协作使用 `VSurface`、`VInput`、`VSelect`、`VChip`、`VButton` 和原生 Markdown renderer。行情、基本面、新闻在各自的原生 Agent/Session 执行，再由独立乐观与审慎分析员检查，最后由主助手汇总。页面只投影原生 Turn 的真实状态和完成答案；运行引用绑定 Session、Turn 和 submission，停止只停止该 Turn。配置漂移、会话归属变化与未知提交都给实际原因，不补造百分比或报告。原始分析员会话通过原生 chat 页面打开。
明确提交基础分析并确认接受后，服务端通过原生持久后台任务继续推进；离开页面不暂停后续阶段。页面轮询等候和运行中的协调记录，阻断原因通过 `VStateSurface` 呈现，不自动重发。完成状态要求精确汇总 Turn 的最终回答；旧记录无协调状态时保留原有兼容路径。汇总失败、停止或缺回答不显示为仍在汇总。
分析卡片按桌面中栏可用宽度自动分列，使用一条完整的 grid template，避免其他延迟路由的基础 grid 样式覆盖断点。`FinanceAnalystTeamInspector` 复用 `VChip`、`VStateSurface` 和 `VButton`，跟随当前选中的研究轮次，显示股票、日期、实际已保存的分析引用与服务端协调状态；归档前的主助手旧标题不混入本轮进度。完整 Turn 引用和已完成协调同时存在时才显示完成，查看汇总跳转该轮次的精确 Session。
已接受的 Turn 在对话读取中或读取失败时显示对应读取状态，进度计数暂留空，不回退为未提交或 0/5。刷新同时重新读取该轮次的精确对话，不能因此重新发送分析。
组合研究使用 `VSurface`、`VMetricStrip`、`VDenseTable` 与 `VButton`，复用当前助手的模拟账本。持仓权重、现金和集中度按实际账本与报价计算；收益相关性仅来自共同日期的真实 K 线，样本不足保留缺值。点击股票回到已有单股页，AI 研究只准备包含账本和来源的原生草稿。

### FinanceRebalance

组合调仓嵌在现有组合研究页，复用 `VSurface`、`VDenseTable`、`VCheckbox`、`VInput`、`VTextarea`、`VButton`、`VStateSurface` 与 `VDialog`，不增加侧栏入口或第二套表单。用户从已完成研究目录选择最多5份精确 Session/Turn，候选代码默认取当前模拟持仓且可编辑；最多10只候选，既有持仓由服务端并入。组合目标和可编辑风控参数先生成建议，所有建议订单、确定性风险检查、行情时效、预计现金、换手与费用都在方案详情中展示。

批量研究结果可以带入组合建议，但候选标的只接受沪、深、北交所 A 股。选择窗口仍显示港股与美股报告并明确禁选原因；没有可导入 A 股汇总报告的批次保留禁用入口和原因说明。所有报告默认未选，用户需明确选择最多5份 A 股精确汇总 Turn；带入后按当前助手、Session、Turn 逐条读取核验，再把所选股票预填到可编辑候选栏。保存的建议始终按自身精确报告引用提供导出；报告目录元数据缺失时显示“原始研究报告”，完整 Session/Turn 留在悬浮说明，清除批次来源信息不改变历史建议的引用。

持仓与相关性表按实际容器宽度自动排列，窄桌面上下展示；沿用 `VDenseTable` 固定可读列宽和表内横向滚动，表头保持单行，股票名称和报价时间在单元格内截断，不挤压会话栏与辅助栏。

历史建议可重新读取；生成请求使用稳定 UUID，结果不确定时先按同一 ID 读回，再允许原请求重试，避免未知结果触发第二次模型调用。编辑目标权重或风险参数后方案标记为已修改，批准保持禁用，只有服务端重新预检并返回新 `planHash` 才可批准。批准弹窗逐笔列出即将写入的模拟订单；过期、风控阻断、执行失败或已修改的方案均不可批准。审批只执行到当前私有模拟账本，不接触券商交易。

## FinanceTaskCenter / FinanceResearchJobs

### 功能与使用
桌面研究任务使用 `VTabs` 区分原生记录、批量研究与定时计划；批量/计划沿用 `VSurface`、`VTextarea`、`VInput`、`VSelect`、`VButton`、`VChip` 与 `VStateSurface`，不增加第二套控件。一次最多 10 只有效 A 股、港股或美股，显示每股状态、完成数量和真实失败原因。查看结果/过程必须指向该股的精确研究轮次；查找失败保持错误态，不能显示最新轮次。
计划明确北京时间、一次/每天/周一至周五，显示下次时间和暂停/恢复；节假日与应用需运行的约束只保留一行。运行中提供停止批次，确定失败或停止提供重试未完成，已完成股票保留。同步请求门和幂等键防重复创建；切换助手隔离旧响应与提示。
既有计划类型增加「A股交易日」选项，仅接受沪深北A股，按已核对的交易所闭市表执行；旧周一至周五语义保留。未覆盖年份显示「日历未覆盖」并停止触发。停机最多补最近一次，显示原计划日和跳过次数；补跑研究日期保持原发生日，不改成今天。

## FinanceResearchReport / financialReports

### 桌面阅读密度
研究报告页使用现有 `FinanceStockHeader compact`：股票身份、价格、涨跌和自选/刷新操作在同一行；来源、可能延迟、行情时点与抓取时点在下一条单行来源栏保留，超出可见宽度时通过 title 读取完整内容。六项行情指标仍在股票概览使用完整头部。报告章节沿用 `VTabs` 的 listClassName/triggerClassName，在桌面宽度内单行横向滚动，长标题省略并保留完整 title，Radix 键盘导航不变；原始研究参数保持单行可滚动，不重复代码形式的公司名。正文与精确 Turn 的核验读取、导出不变。

### 报告交付
报告标题区使用下方 `FinanceReportExport` 的共用导出菜单，支持 PDF、Markdown、JSON、Word 和打印。导出只接受报告自身精确完成 Turn，保留 pending/error，正在研究或缺少最终回答不显示可交付报告。打印在当前页面的无脚本 sandbox iframe 内隔离展示；PDF 生成失败后可下载独立打印版 HTML。HTML 下载仍是 HTML，不标记为已生成 PDF。
打印内容使用有界 `srcdoc`，加载失败或未收到打印完成确认时尝试下载单份报告 HTML，并说明需要在浏览器打开后打印；不打印整个工作台。

## FinanceGroundedReportBody / FinanceReportReadState / FinanceReportEvidenceNotice

新增缺证据占位提示为“部分数字未通过核验”，同时适用于金额、股价、百分比及估值倍数；提示不宣称其他数字已全部核验。提示与「补充证据」图标按钮保持单行，长标题省略；按钮复用原会话追问和附件入口，不自动提交。单股报告返回当前研究会话，团队结果打开所选轮次的综合 Session，不跳到分析员或其他轮次。

### 功能
股票报告与五方研究的主助手综合结论共用精确 Agent/Session/Turn 的 Markdown 导出读取。页面展示和文件导出保持相同的金额证据处理，核验只覆盖该报告 Turn 的原生证据，不宣称完成所有分析员的跨 Turn 审核。

### 适用范围
仅展示已经完成的正式报告或综合结论；分析员角色卡和原生对话保留真实原文。读取期间不展示原文替代品，失败保留重试，切换身份中止旧请求并拒收晚到响应。

### 使用方式
`FinanceGroundedReportBody` 接收精确报告 target、原始回答和语言。共享 hook 供 `FinanceResearchReport` 保留章节与研究参数。`FinanceReportReadState` 复用 compact `VStateSurface` 与 `VButton` 显示加载/失败重试；`FinanceReportEvidenceNotice` 仅在核验正文新增缺证据占位时显示一条 warning，不给全报告通过标记。正文继续使用原生 Markdown renderer，不新增设计 token、布局记忆或存储。

## FinanceResearchConfig

研究表单复用 `VSurface`、`VInput`、`VSelect`、`VButton`、`VStateSurface` 和 `VRouteLinkButton`。模型选项来自身份匹配的当前会话；默认模型和本轮选项的上下文容量、供应商健康、凭据与可执行状态须可确认，失败时禁用开始并提供助手配置入口。新建研究传递已选本轮模型，由目标会话再次校验；五级深度优先映射到不高于请求的最高支持档位，没有更低档位时使用模型最低档位，表单显示实际推理强度，不静默回到更强的默认档位、换模型或扩权。

## FinanceWorkspaceInspector

报告阅读状态附加当前报告的引用列表，使用带独立图标槽的 `VButton` 单行显示来源及页码，点击交给现有引用定位，未列引用时明确显示空态。这里只投影来源引用，不把列出引用视为报告数字已核验；主题报告和股票报告均使用当前对象的引用，其他工作区不显示旧报告引用。

### 功能
复用 `VSurface` 和 `VStateSurface` 展示当前股票或精确报告摘要；标题和元数据单行截断。默认由 `FinanceResearchOverview` 显示研究状态与引用；过程页保留原生 `FinanceResearchProcess`。待核验筛选只投影原生失败和待审查工具事件，可恢复全部事件；不生成新的 transcript 或进度权威。报告和对话操作固定在右栏底部，资料内容独立滚动。
主题研究报告刷新后从原生会话恢复主题身份；辅助栏展示同一研究主题，不能显示工作区之前选择的无关股票。

### 适用范围
桌面股票研究与报告中心的右侧上下文辅助栏。

### 使用方式
报告详情使用独立阅读状态与返回列表操作，保留当前列表筛选；报告选择只携带真实 Session/Turn，目录使用已有 sessionTitle/preview 辨识同名报告。研究报告参数只从所选原始请求投影，缺失值不显示，不将当前模型配置冒充历史执行模型。
行情刷新失败时保留上一份成功数据并提供重试，来源提供的 dataDate、报价 timestamp 与单股缺值原因如实显示，不使用抓取时间冒充市场数据日期。

## FinanceManualPositions

## FinanceReportExport

报告中的粗体小标题与 Markdown 标题共用结论边界，关键事实不会因缺少 `##` 被整篇当作结论。仅当同一原生 Turn 的行情工具成功返回对应股票、币种与有效报价，且同一结论段明确注明股票、来源和报价日期时，保留精确匹配的价格；查询时间不替代报价日期，行情数值不能证明财报结论或计算。中文标点紧邻的裸来源链接在显示与导出投影中明确 URL 边界，原始回答不变。
报告正文与简报复用现有精确 Turn 导出服务的核验正文，不将原生对话的截断工具预览当作完整证据。读取中使用 `VStateSurface`，失败可重试；切换 Agent、Session 或 Turn 后不展示旧响应，所有格式与页面共用同一证据过滤结果。

### 功能
复用 `VDropdownMenu` 与 `VButton` 导出当前精确 Session/Turn 的报告。菜单只保留一个 `PDF (.pdf)`，直接下载本地生成的 PDF，保留中文、表格和分页；字体或生成失败显示当前操作的错误和「下载打印版」后备按钮。Markdown、JSON、Word 与独立打印入口继续可用。所有格式共用同步请求门、取消信号与身份重置，旧报告的延迟响应不得进入新报告。

### 适用范围

  ### AI 回测
同一「历史回测」内容区使用既有 `VSelect` 切换 AI 策略与均线对照，保留三栏与会话优先布局。沿用 `VInput` / `VTextarea` / `VSurface` / `VDenseTable`，不新增导航或基础组件。资金、仓位、频率、成本和调用预算先预检；预检不调用模型，显示实际区间、决策数量、模型、冻结数据标识与阻断原因。开始后读取服务端任务状态，离开页面不取消任务，重新进入可查看历史、停止或继续未完成部分。
数据源复用 `VSelect` 选择腾讯、东方财富或整份快照自动备用，来源失败必须可见。新预览的日成交量上限默认1%，可通过同排数字字段调整；旧运行没有该参数时保留旧算法。订单显示部分成交或不足一手，不把日线容量近似说成开盘可成交保证。研究输入可选仅行情或行情加历史公告；公告仅冻结严格早于每个决策日的标题、来源与链接，最多3只股票、20个股票与日期组合。预检显示条目数和不完整覆盖，全部来源失败时阻断。恢复和派生仅使用原冻结材料，公告预算计入原模型预算，不新增自动调用。

结果使用既有净值图、指标行、决策表、成交表与拒单审计表。启动、停止、恢复和导出都有同步防重复提交及错误态。结果不明的调用须在 `VDialog` 中针对精确日期确认可能重复计费，已成功的决策保留。JSON/CSV 导出来自同一冻结任务。模型只读历史行情和模拟账户；历史训练知识偏差、公司行动检测及交易规则简化随数据预检和结果显示。文字与图标复用按钮专用槽位，单个控件保持同行。
同数据副本从历史回测精确任务创建。策略/模型对照可调整策略、明确选择的兼容模型与 Token 预算；单参数试验一次只改持仓上限、决策间隔、佣金、最低佣金、滑点或成交量参与率之一，其他输入（含策略、模型和预算）沿用源值。每个候选单独预检并由用户逐条启动，不批量调用模型；预检复用冻结行情和日期边界且不调用模型。决策间隔仅允许1、5、20个交易日；公告模式不允许调整决策间隔，也不会重新联网补取公告。纯行情模式调整频率前先核验源日程，再按同一冻结行情重建新日程。旧运行缺少成交量参与率上限时保留旧撮合语义；显式试该参数才增加上限。源模型当前不可选时不静默替换。

AI 回测是独立任务，预检与启动由回测服务校验模型、数据和预算，不因普通研究会话模型选项未就绪而锁住入口。均线结果的“开始AI复盘”仍沿用研究会话就绪检查。
历史比较可按策略、模型或单参数对照选择2–4条当前助手任务。服务端校验共同数据和参数；只有参数轴中目标值不同且其余冻结输入一致时才展示收益指标。未完成或口径不一致时只显示状态、原因和说明。结果不排名：模型调用有随机性，反复试参也会产生选择偏差。比较清单作为当前响应导出 JSON，不建立第二份结果存储。
比较指标复用可调列宽的 `VDenseTable`，表头、模型名与策略摘要保持单行；完整模型标识和策略保留在 title。1280px 桌面仅表格内部横向滚动，禁止挤窄所有列或造成整个页面溢出。

组合模式复用同一表单与任务历史，支持最多10只A股共享现金；预检展示完整股票列表、每股数据覆盖和冻结的样本外起点。默认按交易日历将前80%与后20%分段，用户可在预检前指定日期。结果显示完整目标权重、订单所属股票，以及样本内/样本外的日期、起始净值、收益、基准、超额、回撤与费用。股票代码参与表格行身份，不能用首只股票替代组合身份；旧单股结果保持可读。修改股票集合或评估日期使旧预检失效，尚未接到可靠结果的请求保留幂等恢复入口。

## FinanceBacktestAdvancedEvaluation

### 功能
完成的A股回测提供同一冻结决策下的费用压力情景，以及只基于预先冻结样本外区间的Newey–West统计区间。费用压力通过已有撮合引擎重放，不产生模型调用；统计区间只描述一条历史收益序列。

### 适用范围
只用于已完成且行情快照、决策与完整净值可校验的单股或共享现金A股回测。未设置样本外起点时不计算统计区间。策略、模型、提示、决策频率或研究输入变化不属于冻结决策重放；这些变化须创建独立完整模型运行。

### 使用方式
结果默认收起。展开后可查看原费用、1.5倍及2倍佣金/最低佣金/滑点情景；买入持有基准同步采用相同费用，印花税按历史成交规则不变。表格在内容区内部横向滚动。至少252个样本外交易日才显示95% HAC区间；短样本、方差退化或缺少预先冻结的样本外边界时显示原因，不补造数字。说明文字须持续提示该区间不表示模型成功概率或未来收益概率，也不包含训练知识偏差、模型调用随机性及未建模交易成本。参数敏感性和滚动样本外需要各自的完整模型运行，不得把本组件的成本重放包装成重新训练或LLM复跑。

### 回测费用口径
FinanceAIBacktest 复用既有 VSelect 提供原有简化费用和沪深历史分项两种口径。旧记录不改变；新口径明确佣金含经手费、证管费，过户费另收。选择变化撤销已生成的预检；不因切换模式暗自修改佣金或最低额。仅支持已核实的沪深历史费率窗口，北交所或超出范围由服务返回阻断原因。

费用明细复用 VSurface、VButton 与可调整列宽的 VDenseTable，默认收起；策略、基准分开列示佣金合计、内含经手费和证管费、券商差额、过户费、印花税与总扣费。标签、按钮和表头保持单行，横向滚动只在表格内部。依据仅链接官方 HTTPS 来源。预检及结果都保留最低佣金按模拟订单计算、到分舍入属于模型约定的说明，不把分项审计描述为券商实盘结算认证。
