# Conversation process presentation

## ConversationToolActivity

### 功能

用紧凑、无卡片背景的过程行展示工具动作。普通工具名使用正常字重和次要灰阶；最终回复保留正文层级。单条、批次和类别分组都不显示右侧尖括号。失败、超时和需要关注的状态紧跟动作名称，位于命令摘要或分组数量之前；详情中保留完整错误。

### 适用范围

普通对话的原生工具活动及共用 ConversationToolActivityPills 的旧时间线。只改变呈现，不改变 Session、工具结果、展开持久化和轮次状态。

### 使用方式

继续使用 ConversationToolActivity 的现有 activity、language 和 renderToolDetails 输入。整行 summary 可鼠标点击或键盘展开；状态文字沿用 VTooltip，展开详情保留复制操作。运行中动作文字沿用既有动效与 reduced-motion 支持。

### 思考行与验证

原生 reasoning header 与旧 timeline thought header 继续复用 VButton，显式清除默认及 hover 的背景图片，避免按钮渐变残留为灰色横条。保留焦点轮廓、原有展开行为和耗时摘要。用工具交互测试、过程样式契约、VUI 合约和桌面/窄屏浏览器验证。

### 共享 Codex flow

Chat 和 Launcher 共用同一 flow：状态与权威耗时置于流开头，工作记录和思考分别使用 VButton 控制。运行中默认展示工作记录；有最终回复的成功轮次默认收起，最终回复独立显示。失败、降级、告警、中断和没有最终回复的轮次保留记录入口并默认展开。用户显式选择继续使用会话展开状态，优先于自动默认值；收起时 hidden/inert 隔离内容，内部焦点返回工作记录按钮。

思考默认隐藏；先排除不可见思考再分组相邻工具，进展 Markdown 和错误仍是分组边界。显示思考后恢复原顺序。思考节点保持稳定挂载以保留首次计量，整体记录收起时暂停不可见内容的显示更新，重新展开不重置计时。工具区减少嵌套垂直留白，动作与对象使用次要字色，时长使用更淡的字色；运行中保留动作类型图标，文字动效表达活动状态。旧 disclosure 调用保持兼容，失败、超时和审批 fallback 继续可诊断，不移动到猜测匹配的工具行。

助理动作行优先根据真实 `arguments.action` 使用共享动作标签和显式语义：源码/搜索属于探索，写入属于修改，派遣与浏览器分别使用 Agent 和浏览器图标。投影缺失 action 时才回退生命周期参数；未知动作保留原通用工具名，不从摘要猜测。实体摘要仅取白名单 ID；不同 action 不合并为同名批次。前端投影和显示不改变 Session Journal、worker、SSE 或原生 IPC 的权威。

借鉴 ZCode 的可见项分组、类别摘要和完成态收起，保留本项目 VUI、会话状态与原生工具权威。验证覆盖真实动作、生命周期参数回退、跨隐藏思考分组、完成/失败/无最终回复、键盘焦点和思考耗时，并在实际页面核对宽屏与窄屏效果。
