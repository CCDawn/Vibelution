# Product — Agent perception management

## AgentPerceptionPanel

### 功能
在 Agent 中心为单个 Agent 配置可查询来源、触发条件、后台调研边界和通知方式，并查看服务端记录的运行事实。

### 适用范围
- **适用**：选择 Agent 后的“感知管理”面板。
- **不适用**：知识库 ACL、工具授权、知识写入、审批、个人记忆保存与记忆内容管理；这些权限继续由各自 owner 管理。

### 使用方式
- `AgentPerceptionPane` 按 Agent 查询策略和运行事实，提交带 Agent ID 的保存与取消请求；`AgentPerceptionPanel` 呈现当前 Agent 的数据和草稿。
- 面板入口固定为“感知设置 / 运行记录”，默认进入感知设置。切换 Agent 时回到设置页，避免把上一 Agent 的运行记录误认成当前设置。
- 设置页按全局感知开关、来源、后台调研与通知的顺序展示；运行状态默认折叠在设置之后，固定保存栏之前。摘要不占独立侧栏，也不单独记忆 pane 宽度。活动运行或 runtime 错误时自动展开；停止操作仅在服务端允许取消活动运行时显示，并保持可触达。
- 运行记录页保留详细的执行、读取、用量与知识更新事实，以及关联原生 Session 的入口。

### 结构与交互
- 来源按个人记忆与正式私有知识库、指定团队、共享知识库、本地成熟项目索引四类排列。宽屏用同一组 VButton 直接选择“关闭 / 按需查询 / 自动感知”，每个按钮以来源完整名称和方式完整名称组成可访问名称，并以 `aria-pressed` 说明当前选择；窄屏保留带来源名称的原生 select。两种呈现共享同一草稿状态。
- 团队和知识库范围默认折叠，通过来源行上的范围按钮展开编辑。折叠状态摘要保留已选范围；收起不会清空草稿。团队/知识库按钮和主题编辑按钮的可访问名称分别表达来源与展开/收起动作。来源改为“关闭”也只改变模式，不清除范围和触发配置。团队和知识库选项仍只来自服务端授权过滤后的配置响应；已保存但当前不可读的 ID 继续保留，并明确不会扩大访问权限。
- 每个来源独立设置关闭、按需查询或自动感知，并可配置任务、知识更新和后台计划触发器。按需查询必须保留其原有边界：只有用户在本轮明确要求查询时才读取；Agent 自称获得授权不算用户请求。
- 后台调研单独展示启用状态。关闭时折叠主题和用量参数，但保留草稿值；开启后主题直接编辑，间隔和每日次数位于基础区；每次工具调用、输入 token、结果字符数及固定并发上限收在“高级用量限制”折叠区，并使用紧凑网格。并发上限仍为每 Agent 一个任务。通知策略独立于后台开关，始终可编辑；静音只控制通知，后台关闭也不停止知识更新扫描。
- 保存和放弃修改的操作固定在设置区底部可触达。首次尚未保存策略时，即使默认草稿没有字段差异，也允许明确保存当前关闭策略；保存前继续沿用 Agent 现有行为。已保存策略按 canonical 内容比较，修改摘要逐项标明来源或设置。保存进行中禁用编辑和重复提交；失败保留草稿并可重试。修订冲突保留本地草稿并暂停保存，只有用户显式选择“加载最新策略”才丢弃草稿并重载。
- 通知策略支持仅重要、全部和静音投递。静音不关闭知识更新扫描。通知列表只呈现来源提供的更新元数据；未投递字段表示待处理的新更新，不代表静音状态或真实外部送达回执。

### 来源和事实
- 来源范围按该 Agent 有界个人 episodic memory 与正式私有知识库、指定团队、共享知识库、本地成熟项目索引分组；团队和共享知识库选项由服务端按权限过滤。
- 运行摘要默认只展示状态入口，用户可显式查看详细运行事实；活动运行或 runtime 错误时自动展开。展开后的“当前可用”读取 runtime `readableSources`，只反映策略与当前权限允许的来源；“最近实际读取”只展示服务端最近记录 `lastActivity` 的时间、来源与用量。活动任务单独以“正在运行”展示，其来源只读取 `activeRun.sources`；该数组为空时显示无读取来源状态，不能用最近记录的来源补上。停止只使用服务端 `activeRun.runId`。任何实际读取来源都不得从当前策略草稿推断。
- 运行记录页展示服务端实际运行、来源读取和知识更新通知。知识库名称使用当前授权映射；本地项目索引用 `local-project-governance` 标识并显示为“本地成熟项目索引”。

### 组合方式
页面使用现有 `VSettingsFormPage` recipe 提供页头、标签工具栏、滚动设置主体和固定操作栏；页头状态始终显示服务端已保存策略，草稿开关变化不会伪装成已生效状态。主体组合现有 VUI API，包括 `VSection`、`VSurface`、`VSettingsGroupCard`、`VSettingsRow`、`VFieldRow`、`VCheckbox`、`VSwitch`、`VNativeSelect`、`VInput`、`VButton`、`VChip`、`VStateSurface`、`VContextualHint` 和 `VTabs`。不再使用 `VSplitWorkspace` 承载设置页或运行摘要侧栏。不在业务路由直连 shadcn renderer，不新增并行控件或第二套设计系统。

`AgentPerceptionPanel` 属于 `routes/agentPerception` 的页面组合，没有新增 `components/vui` 独立导出组件。来源授权、草稿和原生 Session 运行记录由所属页面提供；沿用既有 API 和持久化边界，不引入新服务端 API、独立范围存储或 pane 宽度设置。

### 信任边界
- 保存配置只改变 Agent 感知策略，不增加 ACL 或工具能力，也不改变 episodic memory 保存权限。
- 未保存策略时延续既有行为；显式保存关闭后阻止后续感知读取，不清除已经进入会话的内容。
- 运行事实不得从策略决策或当前可读数量推断。通知只显示服务端提供的元数据，不把正文或摘要伪装成通知内容。

### 反冗余
- 继续使用 Agent 中心现有 pane、VUI 设置行和表单 primitives；不另建通用 perception 表单库。
- 后台研究预算与来源边界由策略 DTO 持有，页面不保存第二份持久状态。
