## 预览覆盖与实现边界

- 流程页：阶段聚焦/全流程、五节点折行、节点选择、当前任务定位、上下文区分。
- 阅读区：概览、支持/反证/缺口、示例文献定位、运行记录、当前任务讨论。
- 题目档案：题号/名称搜索、无结果提示、进入题目当前任务。
- 团队页：成员职责与任务讨论入口。
- 状态：待补证据、运行中、读取失败及恢复、未选题目。
- 窄屏：阶段与详情抽屉，正常文档滚动，Escape 关闭弹层。

阶段聚焦使用隔离的布局草图 `FocusedStagePreview`，便于评审折行与字号；全流程复用真正的 `VWorkflowCanvas`。正式实现不能把该草图变成 routes 中的第二套画布引擎，布局和交互扩展必须进入现有 `components/vui/renderers/shadcn/workflow`，由 VUI 产品 API 暴露。

示例题目名称、文献、状态、数量和讨论均为模拟，不代表真实 SCI-003/SCI-091/SCI-020 的科研事实。没有真实模型、检索、提交、审批、停止、重置、知识发布或远端写入。已有审批和知识发布边界保持独立验收。

## 验证

- `tsc -b --pretty false` 通过。
- VUI 路由与组件设计契约检查通过。
- 1440×960：聚焦页五个节点完整可见，节点宽度超过 245px、高度至少 120px；点击未开始节点不会展示当前任务产物。

- 导航：可进入全流程、返回当前任务、搜索题号并进入对应题目。
- 状态：读取失败可恢复，未选题目可直接进入题目档案。

## 批准后的正式实施

1. 将已确认的阶段可见范围与折行布局接入现有画布，避免把新展示结构写入研究业务状态。
2. 整理当前任务/所选节点/题目目录三种语义，替换正文内部字段名，合并重复导航。
3. 按已有 API 接入节点证据、运行记录、题目查找与讨论，验证题目切换时数据归属；缺少真实来源能力时单独报告。
4. 运行对应模型、布局、路由与 VUI 契约检查及 TypeScript 构建；用真实运行页面走只读主路径。已有真实写动作的权限和语义不能由 UI 优化改变。
5. 自审后按项目流程合入本地 main；是否刷新真实运行时依据 Launcher 与 active-work guard 判断。远端 push/PR/发布不在本次授权内。

用户已批准阶段聚焦方案，并要求投影与状态统一。正式实现复用 workspace/context 状态，删除选中候选数推断状态及导航文案推断阶段的旧路径。知识子流程详情只请求所属 child run，不再以 ksf_ 展示 ID 请求 parent run。模型与资源、会话诊断及子流程概览默认折叠；无预算记录或有效上限时不显示百分比。

正式联调：首次真实 SCI-003 页面已验证聚焦视图与主/子任务标识，随后修复正文栅格挤压和子节点误请求。后续真实页面的主流程 snapshot 返回 200，但 state-v2 等请求持续等待，完整实时交互验收受此限制；没有重启或停止科研任务。代码交互回归覆盖真实组件、切题竞态、状态归属、命令权限和读取失败。
