# Agent 感知管理

状态：需求与控制中心交互预览已获用户确认，正式接口、界面与原生运行链路已接入。缓存前缀稳定与真实 provider 缓存使用量分别验收。

## 用户结果

入口为控制中心 → 选择 Agent → 感知管理。用户设置永久范围，Agent 只在允许的自动来源内按任务临时启停。个人、指定团队、选定/全部已授权知识库、本地成熟项目索引分别可选关闭、按需查询或自动感知。按需查询须有本轮用户明确要求，不能被模型自称授权。

任务检索、知识更新通知、后台主动调研是三个独立触发器。后台调研目标由用户配置，频率、每日运行次数、每次工具/输入额度和并发均有上限。通知可合并和静音，显示来源、相关任务与结果。写入、审批和个人记忆保存独立管理。

## 状态权威

| 对象 | 唯一权威 | 派生内容 |
| --- | --- | --- |
| 永久感知策略 | Agent metadata.perceptionPolicy，由现有配置事务保存 | 控制中心配置与策略指纹 |
| 可读取内容 | 现行 MemoryPolicy、Owner ACL、ToolPolicy 的交集 | 当前有效来源 |
| 后台执行 | 原生 Session worker / Journal | 任务登记与进度引用，不另存 transcript |
| 检索内容 | 固定版本知识及项目源文件 | 有界、标记不可信的引用与工具尾部结果 |

没有新配置的 Agent 保持原行为；显式保存关闭配置后停止后续感知触发与读取，既有数据及会话历史保留。严格隔离已进入对话的信息需要新会话。新策略不修改个人记忆保存开关，不授予任何 ACL。

感知开关控制知识检索、更新扫描和后台调研，不替代通用文件与命令工具的权限或沙箱。具有文件/命令权限的开发 Agent 仍按现有 ToolPolicy 与路径边界读取工作区文件；关闭感知不能作为完整的数据隔离保证。后台调研仅可使用已授权的知识检索工具。

## 缓存与集成

检索工具 schema、排序和静态 Prompt 保持稳定。变化的启停状态与检索结果进入当前轮动态尾部，不在历史消息前反复重写 system。已有有效快照保留。

新配置 Agent 的个人记忆通过本轮有界检索读取，不再预取整段个人事件。按需许可仅从可信宿主的原始用户消息识别，引用文档、代码、Agent 消息和后台主题不能提供该许可。每个来源单独判断；一个来源的用户请求不能解锁另一来源。

界面区分已保存策略、当前读取权限下的来源范围和真实执行记录。`readableSources` 说明策略、MemoryPolicy 与知识库 ACL 下的范围，执行时仍须复核本轮工具授权；`lastActivity` 记录实际来源读取及计数，不能把范围显示成 Agent 正在读取。后台输入额度按每次完整模型请求估算并累计，工具结果长度跨该次调研累计；并发为每个 Agent 最多 1 次。

正式界面沿用已确认预览，使用 VUI 组件与现有 Agent 详情工作区。配置、运行状态和取消接口由操作者控制通道调用，保存以 Agent 的当前修订作并发检查。通用 Agent 创建和 metadata 修改接口不能绕过感知配置权限。

读取服务覆盖有界个人 episodic memory、Agent 私有正式知识库、选定团队、授权知识库和本地成熟项目治理卡片。知识库选择和排除使用完整 owner-scoped ID，避免同名知识库扩大范围。Agent 可请求已配置范围的子集；每次读取重核策略、ACL 和工具授权，策略变化时丢弃在途旧结果。

后台调研使用独立的隐藏原生 Session，其 Journal 与 worker 仍是唯一执行和对话权威。持久感知状态只保存标识、hash、游标、计数和原生会话引用；取消对精确 turn 请求停止。服务恢复后先核实已有原生 turn，保留已消耗额度，不重放无法确认的提交。工具调用与来源读取分别计量，避免一次工具检索重复消耗调用额度。

完整重启会使旧后台许可失效，旧运行收为中断且不退还已消耗额度。关闭后台后清除下一次调研时间；重新开启或改变间隔时从保存时间按新间隔排程，其他设置变更不推迟现有计划。

知识更新扫描限定在已启用的来源和当前 ACL 内，第一次扫描建立基线，之后比较 revision/hash、合并同条目通知。重要通知依据操作者主题筛选，静音仍推进游标。通知与读取结果不自动写入正式知识。成熟项目来源当前限治理卡片与证据定位符，源码读取由独立能力提供。

验收分别记录测试、隔离 HTTP、正式界面、原生执行和 provider cache usage。静态 Prompt 与工具 schema 一致仅证明缓存前缀稳定，不能代替真实缓存命中率测量。
