# Security 生成物

本目录存放**生成/扫描类**安全材料，**不是**日常开发红线正文。

| 文件 | 说明 |
| --- | --- |
| `action-risk-classification-*.json/html` | 动作风险分类导出 |
| `tool-vulnerability-report.*` | 工具漏洞扫描报告 |

## 使用方式

1. 打开前核对生成日期与扫描范围。
2. 若与现行工具授权冲突，以 [`docs/agents/tool-authorization-entrypoints.md`](../agents/tool-authorization-entrypoints.md) 与代码门为准。
3. 过期快照可迁入 `docs/archive/security/`（需要时再建）。
