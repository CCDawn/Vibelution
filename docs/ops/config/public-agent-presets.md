# 公共 Agent 预设与全新部署

公共预设保存在 `core/web/services/agent_directory/presets/catalog.json`。
它发布可重建的角色配置，由首次启动初始化创建新的 Agent 身份和原生 Session。
仓库不携带开发者的 Agent ID、会话记录、个人记忆、知识库授权或 API 密钥。

## 随仓库提供的独立预设

| --- | --- |
| 洛天依 | 人格、任务设定、头像、城市与生活节律配置 |
| 能力顾问 | 组织与能力咨询提示模板、工具和模型偏好 |
| 资料 Agent | 资料整理角色、定制提示模板、工具和模型偏好 |

| 迭代决策 | 独立迭代规划角色配置 |

旧科研角色作为独立 Agent 保留。当前科研团队仍使用搜索、提炼、知识管理、执行、
实验修订、评估六个正式成员；预设初始化不会把旧角色重新插入团队。
知识扩充团队的“资料入库”和这里的独立预设分别匹配其创建来源。

## 首次启动与重复启动

Session 存储就绪后，功能路由开放前会初始化缺失预设。
Agent、工具策略、人物配置和会话仍通过既有服务写入。
初始化中断会继续补完同一个预设，不创建第二套会话。

已有同名、同角色、同来源的实例会直接复用。已完成预设的模型、提示词、权限、
人物绑定与生活开关保持用户设置；归档实例不会因重启复活。
所有新预设默认使用 `request_approval`，工具执行继续经过原生权限与审批。

## 模型配置

预设保存模型偏好引用和非敏感参数，不包含厂商凭据。
当前部署的模型库能够解析该引用时使用对应模型，否则使用部署者配置的默认模型。
尚未填写任何模型凭据也会创建 Agent 和会话，避免功能页没有 Agent 可选。
配置模型后可以在 Agent 管理中调整绑定；重启不会覆盖已有选择。

## 洛天依与辅助角色

全新部署会提供已绑定的洛天依，并创建“洛天依的生活管家”和“洛天依的自主行动”
两个原生辅助 Agent 与会话。后续正式生活流程会复用这些身份。

初始人物在大厅可见，可以进入聊天；后台生活处于暂停状态，主动消息关闭，
自治等级为辅助模式。初始化不调用模型、不发送消息、不复制开发者的生活历史。
在人物页面恢复生活、确认生活设定，并配置模型后，可继续启用对应功能；
自主行动还需明确开启自治模式。

人物头像来自本地洛天依角色现有的自定义头像，经用户授权随公共预设发布，
文件为 `core/web/services/agent_directory/presets/assets/luo-tianyi.png`。
既有 Live2D 与桌宠模型素材继续遵守各自资源目录的授权说明。
