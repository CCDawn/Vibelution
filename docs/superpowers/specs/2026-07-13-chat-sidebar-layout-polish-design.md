# 会话侧栏排版优化设计

## 目标

将聊天页左侧会话索引调整为安静、紧凑、易扫描的工作台导航。只修改前端结构和样式，不改变会话分类、查询、创建、重命名、拖拽、上下文菜单或后端协议。

## 信息架构

侧栏分为三个稳定区域：

1. 顶部搜索与“新建会话 / 新建群聊”操作。
2. 中部可独立滚动的会话分组和群聊创建表单。
3. 底部固定的“系统入口 / 助手通知流”。

最新数据模型继续把普通会话与个人 Agent 会话投影到同一个“个人会话”分组；本设计不修改该模型。

## 视觉契约

- 搜索框由一个完整的 36px 容器承载图标和输入框，不再出现图标与输入边框分离。
- 两个新建操作等宽排列；新建会话保持主操作色，新建群聊保持中性。
- 分组标题高度为 34px，无整行描边；数量使用弱化的等宽数字，不使用胶囊背景。
- 会话行使用透明列表面，普通状态无边框；hover 和 selected 才出现背景。
- 头像及其网格列统一为 30px；普通行最小高度 46px。
- 标题和时间位于首行；时间不重复显示时钟图标。
- 角色标签最多占一条轻量元信息行，高度 18px。
- 当前会话仅使用左侧强调条、淡背景和 `aria-current`，不再显示“当前”徽章。
- 系统入口以顶部分隔线与会话树区分，并固定在侧栏底部。

## 状态和响应式

- loading、empty、error、群成员视图和群聊创建表单沿用现有行为。
- 会话树超出可用高度时只滚动中部区域，顶部操作和底部系统入口保持可见。
- 侧栏 overlay 和桌面可调宽布局沿用现有响应式机制。
