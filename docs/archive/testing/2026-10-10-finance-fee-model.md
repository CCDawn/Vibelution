# 沪深 A 股历史费用验证记录

本轮增加显式 `verified_ashare_fees_v1`。缺省及显式 `legacy_commission_stamp_v1` 保留原参数摘要和执行方式。复用冻结行情、单股/共享现金组合撮合、存储、worker、比较器与 VUI，不接券商、不写模拟账户或原生会话记录。

## 费用契约

- 新模式限定沪深 A 股，日期从 2015-08-01 起；北交所及更早日期不进入该核验范围。
- 客户佣金包含经手费与证管费，二者只做归因拆分。实际扣款为佣金、过户费及印花税之和，不重复扣除内含规费。
- 经手费按 2023-08-28 分段，过户费按 2022-04-29 分段，印花税按成交日及买卖方向计算。策略与持有基准共享同一费率来源。
- 佣金必须覆盖区间规费且不超过 30 bps，最低佣金至少 5 元；不静默提高用户输入。分项取分导致内含费用超过总佣金时明确阻断。
- 买入可负担数量包含过户费；卖出费用不足以支付时拒单，现金和持仓保持原状。费用进入现金、成本、卖出净额和评估窗口；未成交订单四项费用为零。
- 费用模型与完整审计进入冻结参数和比较指纹。恢复、派生及滚动子任务保留版本；审计被改时在模型调用前阻断。
- JSON schema 5 包含费用审计和冻结输入；单股 price-only 也带完整行情快照。CSV 记录实际分项，两账户分开。旧导出版本保持兼容。

## 验证层次

专项回归覆盖历史费率边界、重复扣款、现金保护、参数兼容、审计摘要和响应类型；最终完整选择器由绑定提交的收口 manifest 记录。前端复用现有 VSelect、VSurface、VDenseTable 与 VButton；费用明细默认收起，宽表只局部滚动。VUI 契约、TypeScript 与生产构建分别验证。

公开输入对账使用已冻结的招商银行 `sh600036` 2025-07-09 至 2025-07-14 行情与官方现金分红公告。冻结行情摘要为 `fa3555174a9ac67e814a0c99831aac5060c83dcab7a8529e536abf41fbbb7431`。确定性策略费用 35.71 元，其中过户费 1.04 元；持有基准费用 30.66 元，其中过户费 0.99 元；两账户各确认股息 4,200 元。逐单费用及现金对账通过，未调用模型，不作为投资绩效证据。

隔离实例通过正规 Launcher 刷新，实际 HTTP 招商银行预检和桌面表单贵州茅台预检均成功，未启动模型。Electron 验证费用默认收起、展开、策略/基准明细和 JSON/CSV 下载；结果来自明确标注的公开输入确定性夹具，只拦截页面响应，不保存为产品回测。费用结果、冻结输入和导出 schema 则由真实 store/worker/响应 DTO 的离线集成回归验证。

同一隔离构建在 Chromium 1280×800 与 1920×1080 中完成截图审查：页面宽度与视口一致，没有全页横向溢出，明细表右侧“总扣费”通过局部滚动可达，页面无未捕获错误。这些尺寸截图属于 Chromium 证据，Electron 证据是实际预检与交互。

桌面验收证据及脚本保存在 Git common-dir `vibelution-cache/task-evidence/finance-ashare-parity/`，包括 `fee-public-reconciliation.json`、`fee-live-preview.json`、`fee-live-ui-preview.json`、`desktop-fee-acceptance.json` 和两张桌面截图。真实预检、结果界面夹具、导出契约和撮合验证分别记录，不互相替代。

## 证据边界

审计保留 `roundingStatus=unverified_broker_settlement` 与 `minimumGranularity=simulated_order`。四舍五入到分和每个模拟订单一次最低佣金是模型约定，不能冒充券商逐笔清算认证。2022 年过户费调整有中国结算官网大事记及现行收费表，尚缺原通知正文官网直链；审计向用户明示。

历史 ST/上市初期状态、送转及零碎股、北交所历史完整费用、账户真实清算粒度仍有缺口，不能宣称完全追平成熟项目。这是兼容的新增模式，无依赖或发布版本调整，未推送或发布。只允许刷新本任务隔离实例，共享主运行未刷新。

费率来源由 `fees.py` 的单一版本化规则及审计列出，包含上交所、深交所、中国结算、财政部与税务总局官方材料。本归档不构成新的开发规范。
