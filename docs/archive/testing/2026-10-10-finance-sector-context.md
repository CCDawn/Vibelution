# A 股当前板块上下文验证

复用现有行情工具的原生授权、研究日期与同运行 Journal 证据投影，通过可选 `include_sector` 补充行业、板块报价和最多五个同业。没有新工具、新权限、REST 路由、依赖、UI 或普通 Session 写入。

## 复用与边界

对照 TradingAgents-CN 社区固定 HEAD `51060a7682cf51810b4bc3a704829438d18cd8dc` 的 `core/tools/sector_tools.py#get_sector_analysis`，只借鉴板块职责，不复制源码，不要求收费数据或券商账户。本地改造行情 facade 和既有工具，默认参数为 false，不增加隐式板块读取。复用裁决记录在 Git common-dir 中。

东方财富股票 f100 是供应商当前行业标签，不是官方行业分类。仅在完整行业目录里唯一精确匹配 f14 才确定 BK 代码；板块 f86 与同业 f124 分别校验，f124=0 不作为板块时点。保留独立源 URL 和时间，不称同步收盘，不输出未经核验的量额、资金流、轮动或概念。历史/未来研究日零板块网络读取，明确 unavailable。

行业分类观察时间与股票报价时间分离。综合报告只从同研究 run、Agent、Session、Turn、Submission 的成功原始行情工具输出读取；白名单投影校验股票代码、来源、URL、数值和时间，当前分类只进入同日研究，不取得原文财报审核身份。异常板块不移除有效个股证据。

主报价与可选板块有独立失败状态；工具输出不超过3200字符的完整 JSON，板块子结果不超过1600字符。预算不足时先缩减同业、板块或省略可选上下文，再裁剪主日线，不因可选来源失败抹掉个股报价，不修改缓存对象。读取期间跨北京时间午夜时清空可选结果，防止次日分类进入前日研究。

日志复用原生工具执行与 Journal，无新增保存用户问题或完整工具结果的日志。属于后端功能补充，无破坏性兼容变化、不发版本、不 push。隔离工具执行与源码测试不能证明共享主窗口已经加载；共享运行时不自动重启。
