# 历史研究覆盖与回测分段评估验收

2026-10-09；本文件记录本次实现和验证，不是新的产品规范。

## 实现边界

- SEC 历史请求读取适用归档，最多4份、每份最多8MB；截止日前的 recent 只有在公开申报与标准财报足够时才跳过归档。官方归档路径绑定发行人，申报编号允许第三方代报机构前缀；指标仍绑定精确 accession，历史请求不使用当前 F10 替代。
- CNINFO 在首屏没有合法定期报告时按需翻页，最多4页，维持截止日与原文身份校验。未取得报告仍走原有缺失状态。
- 回测只请求必要预热年份，保留显式 raw/qfq 与指数日历检查。缺失复权、日期不一致、公司行动仍阻断。
- 完成任务的冻结净值按自然年与63个交易日分段；预设样本外边界存在时只评估样本外。四个完整窗口是占比展示门槛，尾段不计占比，年度不认证为完整全年。
- 分段评估为只读投影；旧记录依据不全显示不可用。VUI、JSON、CSV 共用结果，不新增存储、模型调用或交易入口。DTO 为可选增量，不改变原有回测执行或比较契约版本。

## 复用与验证

参考本地固定版本 Microsoft RD-Agent `32b3d395e73d9db5eee3fe9063d69aec0fdc83bd` 的 Qlib 模板中测试区间、基准、费用与训练/验证分离方式。沿用现有冻结快照、连续账户、评估函数和 VUI，不引入 Qlib 或复制仓外实现。

自动化验证覆盖历史 cutoff、归档路径与身份、代报机构 accession、跨分页财报、窗口基准与费用、短样本/不可用状态、旧 DTO、HTTP/OpenAPI 与 JSON/CSV 一致性。前端类型检查、构建、既有回测交互与 VUI 契约通过；构建仍提示既有大型 chunk 与动态/静态混合 import 警告。

- CNINFO：`600036`，截止2020-12-31，取得四类定期报告，公告日2020-03-21、04-30、08-29、10-31。

- 仅启停本任务的隔离 Launcher 实例；共享主实例未刷新。交付代码与生产运行时生效是不同验收层。

## 桌面验收

隔离实例通过正式 Launcher 启动，真实页面在1920×1080与1280×900验收。仅当前临时浏览器页拦截回测列表/详情请求，使用确定性引擎生成的500日合成 DTO（259日样本外，4个完整窗口加7日尾段）；页面明确标注合成样本。没有往产品存储写入 fixture，也没有调用模型。
