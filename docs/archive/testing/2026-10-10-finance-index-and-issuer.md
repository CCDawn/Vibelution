# A 股指数上下文与官方发行人身份验证

本轮补齐五大指数的公开只读工具、行情角色接线和同一研究运行的原始工具证据投影，修复巨潮资讯数字及 GD 开头发行人身份被拒绝的问题。没有增加 REST 路由、前端页面、依赖、交易权限或 Session 核心写入。

## 对标与本地复用

参考 TradingAgents-CN 社区版固定 HEAD `51060a7682cf51810b4bc3a704829438d18cd8dc` 的 `core/tools/index_tools.py#IndexAnalystV2`，只借鉴指数上下文职责，没有复制源码或要求用户提供 Tushare/QMT 服务。复用本地有界读取/缓存、原生研究截止日期、目录工具权限、团队角色与 Journal 证据权威。仓外参考及裁决由 active registry 生成 common-dir 复用记录。

## 行为

- 固定上证指数、深证成指、创业板指、沪深300和中证500；单位为点，使用原始指数日线，不套股票复权、成交手数或未核验成交额。
- 当前模式同时读报价和日线；历史模式不请求当前报价。超过截止日的日线被剔除并显示 partial，不伪造时间戳。失败按指数逐项呈现。
- 工具 schema 限定日线数量2–20；输出为不超过3200字符的完整 JSON。裁剪只缩短日线，保留五项覆盖和源时点，记录省略数量，不修改缓存。
- 行情研究包可发现新工具，工具需要显式网络只读授权。行情角色只取得主助手已允许的 optional 指数工具，其余角色不取得该工具。
- 默认旧助手和旧行情角色只在显式创建/配置操作升级。查询助手不写权限；定制、禁用或无网络策略保持原状。升级保留原 Agent/Session/Team 身份和调用限额，使用策略指纹防止覆盖并发修改。旧各代默认策略及直接创建入口都在原生 Turn 忙时拒绝升级，团队在第一次写入前检查主助手和行情会话。
- 综合研究只接收同 run、Agent、Session、Turn、Submission 的成功原始 Journal 工具输出。校验固定代码、来源、单位、截止日期、数值和 OHLC，拒绝重复键及异常输入。指数保留为不可信公开参考，不授予财报审核身份；板块覆盖明确为 unavailable。
- CNINFO 仍要求精确六位 A 股代码，按现有 A 股代码规则选择交易所目录。支持实测数字/GD orgId，旧交易所前缀冲突拒绝，同优先级身份冲突拒绝，不做北交所历史代码别名。身份词法长度约束用于保护传输，不冒充官方 schema。

## 验证与限制

聚焦测试覆盖源解析、截止日期、权限、注册/发现、升级幂等、忙会话无部分写入、同运行证据隔离、异常输入拒绝与历史 PDF 目录。最终选择器和 changed-line 检查绑定本次提交，结果保存在正式验证 manifest，前一批费用 manifest 不作为本次验证。

2026-10-10 使用正式 ToolExecutor 和隔离测试身份对真实腾讯免费端点读取当前及2026-06-30历史指数；两次五项均 available，均通过报告投影，输出2695/2755字符。该验证没有模型调用，没有创建产品研究记录，不等价于实际 LLM 已经使用新工具。原始结果为 common-dir `vibelution-cache/task-evidence/finance-ashare-parity/index-native-public-live.json`。

真实巨潮资讯 topSearch 的六个身份样本成功解析；002656及300750在2025-12-31截止日内都取得四类定期报告目录，300750历史PDF目录取得30条元数据。这是官方目录读取证据，没有下载/审核报告全文。一次短时查询超时后有界重试成功，免费来源可用不代表稳定性承诺。证据为同目录 `cninfo-modern-identity-live.json`。

本轮无新增独立日志：正式工具执行、目录策略更新及原生 Journal 已覆盖调用与来源权威，源异常通过现有状态/覆盖字段返回，不额外保存用户问题或完整工具输出。现有团队 GET 的旧身份字段回填未改变，助手 GET 的工具权限保持只读。没有版本发布、push或共享主窗口刷新。

尚未闭环的能力包括可靠免费板块与社交舆情、历史 ST/上市初期限幅、送转配等公司行动，以及跨股长期真实模型验收；不能据本批宣称全面追平。
