# A股研究智能体补齐实施记录

用户2026-10-10要求补齐八项差距，随后限定只处理A股。本文是任务计划与证据记录，不替代现行规范。现有港美股入口保留，不新增其能力；不接券商实盘，不购买数据，不扩原生Session/Journal/SSE权限，不擅自重启共享实例。

## 任务与依赖

| 任务 | owning surface | 验收 |
| --- | --- | --- |
| 历史数据来源与覆盖 | financial_backtest/data、transport及数据适配模块 | 原始OHLCV/复权/日历验证；多源不混淆；真实区间与缺数失败证据 |
| 公司行动及交易规则 | 单股与组合撮合、快照契约 | 登记/除权/支付/上市日期准确；股数、现金、基准对称；不臆测缺失字段 |
| 历史研究回放 | preview冻结输入、decision与runtime | 每次输入有来源与发布时间且不超决策日；恢复不重新取得未来数据 |
| 真实长期模型验证 | 现有显式preview/start/stop恢复流程 | 冻结预算与多股票/多阶段记录；与固定规则验证明确区分 |
| 分析师证据贯通 | team_evidence、runs._synthesis_prompt | 精确原生run/Agent/Turn/Submission；工具材料不升级成已核验数字 |
| 严格评估 | advanced_evaluation、service/DTO/VUI | 成本压力、Newey–West HAC条件区间、真实完整run的参数/滚动比较；不把冻结信号重放称为模型复跑 |
| A股持续运行 | financial_jobs与trading_calendar | 官方交易日覆盖；未知年份停止；停机最多补最近一次且保持历史日期、幂等记录 |
| 桌面与运行验收 | 既有VUI桌面入口 | 1280/1920；错误/空状态/恢复；主实例刷新单独遵循Launcher授权边界 |

数据、公司行动、撮合和历史输入由主线程串行整合；调度、分析师材料传递、独立评估模块并行开发。共享service、backtest DTO、主UI入口由主线程整合；先验证领域行为，再最终统一类型/构建、接口、桌面与合入。

## 权威与兼容

| 事实 | 唯一权威 | 派生与写入边界 |
| --- | --- | --- |
| 回测输入与决策 | Agent-owned immutable snapshot/run store | 分段与压力评估只读；新输入版本有摘要、旧记录不追认 |
| 分析师原文/工具结果 | Native Session Journal | 根据精确run引用读取；不生成第二份transcript |
| 调度配置与发生记录 | financial_jobs store | runtime单writer；同occurrence幂等；不批量追补历史模型调用 |
| 官方交易日 | 带年份/来源/发布日期的日历材料 | 未覆盖年份明确不可用，工作日与交易日语义分别保留 |
| 模拟现金和股份 | 对应回测或paper原有ledger | 不互写，不产生真实订单 |

## 初步事实

- 多智能体证据桥接已存在，过去清单的“未贯通”说法过宽。本次补缺少的来源材料传递，不放宽PDF数字认证。
- 免费分红摘要能取得实施比例和除权日，但不一定具有派息日、股份到账日。缺这些字段时不能假设除权当天即可花费现金/卖出红股。
- 现有303交易日验证是固定规则撮合，不是长期LLM绩效。任何真实模型验证需保存范围与预算，不能据回测收益承诺未来表现。

## 进度

- 已完成范围与owner划分，当前进入实施。各项未取得对应验收证据前不标记完成。
- 用户已明确采用公开免费来源。新增东方财富整段备用适配；2025年末43交易日腾讯实测完整，东方财富同请求两次连接中断，不能宣称备用源已通过端到端可用性验收。
- 真实配置模型在通威股份303交易日完成16次价格输入决策，预算及结果见[实测记录](../testing/2026-10-10-a-share-public-source-validation.md)。另两只股票被公司行动检查阻断，跨股票长期验证尚未闭合。
- 公告模式已贯通预检冻结、预算、Worker 本地读取、派生复用及 JSON 导出。仅使用严格早于决策日的标题元数据，最多3个标的、20个标的/日期组合；缺漏保留 partial，不宣称完整历史财报重放。
- 新回测默认最多使用日成交量的1%，支持部分成交；策略与基准采用相同限制。旧回测未声明参与率时保持原执行规则。日线容量不等于开盘可成交量。
- 交易日调度覆盖已核实的2024–2026年交易所休市日期，未知年份停止；停机仅补最近一次，保留原计划日与跳过次数。
- 已增加1×/1.5×/2×费用压力重放及足够样本外数据下的 Newey–West 条件区间。独立单参数派生仍走预算预检和明确启动；没有实现滚动训练，也不自动推荐收益最高者。
- 分析师证据传递复用原生 Journal 中精确的 Agent/Session/Turn/Submission 引用；工具来源材料保持不可信参考，不升级成已核验财报数字。

## 交付边界

公司行动完整账本、跨股票长期模型验证、历史公告全文/财报数值版本、滚动训练与参数选择、历史 ST/上市规则及逐笔流动性尚未完成。北交所代码格式支持不等于真实数据端到端验收，目前没有北交所实测样本。用户选择免费数据不会消除这些证据限制。

本轮不发布新版本，不变更依赖；JSON 公告导出使用 schemaVersion 3，旧纯行情导出继续使用原版本。共享主实例未重启，桌面验收使用隔离任务实例；源码合入与主实例刷新分别报告。
