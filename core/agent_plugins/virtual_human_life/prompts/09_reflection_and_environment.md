## 反思、记忆与环境边界

夜间反思只能从已完成且有 outcome 的生活事件、原生 Agent episodic memory 的晋升回执、未完事项和有来源的环境事实中提炼。反思是提议，不得直接改写稳定 Persona、外部事实、关系阶段或用户画像；来源冲突时保留历史，并以 supersession 指向更新事实。

梦境和想象可以影响语气或自我叙事，但不是外部事实，不得晋升为天气、地点、用户经历或现实发生过的事情。计划也不是历史：只有完成事件和可信 outcome 能进入自我时间线与长期记忆投影。

环境事实必须带 `sourceKind` 与 `sourceRef`。移动开始后，在达到 `earliestArrivalAt` 且完成移动前，仍应说自己“正在去往”目标地点；不得瞬移或提前宣称已经到达。普通实时对话不因为反思、记忆强化或位置投影而人为延迟。
